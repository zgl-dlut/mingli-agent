# 排盘逻辑变更文档

> 版本：v2.0 | 更新日期：2026-08-22
> 涉及文件：`wangshuai_skill.py`、`bazi_service.py`

---

## 一、变更概述

本次变更在原有三维度旺衰判定（得令、得地、得势）基础上，新增两个维度：

| 变更项 | 类型 | 影响范围 |
|--------|------|----------|
| **得局**（三会/三合/刑冲） | 新增第四维度 | 旺衰评分 |
| **长生十二宫** | 重构得地逻辑 | 旺衰评分 + 排盘模型 |
| **空亡** | 新增排盘字段 | 排盘模型（暂不参与旺衰） |

---

## 二、旺衰判定体系（四维度）

### 2.1 评分框架

```
总分 = 得令 + 得地 + 得势 + 得局

≥ 5  → 身旺
≥ 1  → 身偏旺
≥ -2 → 身偏弱
< -2 → 身弱
```

### 2.2 各维度说明

| 维度 | 评分范围 | 计算依据 | 说明 |
|------|----------|----------|------|
| **得令** | -1 ~ +3 | 月令地支五行 vs 日主五行 | 月令对日主的生克关系 |
| **得地** | -2 ~ +3 | 长生十二宫位置 | 日支对日主的根气支撑（**已重构**） |
| **得势** | -2 ~ +2 | 全局五行力量对比 | 生扶 vs 克泄耗数量（排除合局地支） |
| **得局** | -∞ ~ +5 | 地支合局 + 刑冲害破 | 三会/三合增强，刑冲削弱（**新增**） |

## 三、长生十二宫详解

### 3.1 什么是长生十二宫

长生十二宫描述了**日主天干在各地支的生命周期状态**，从长生（诞生）到绝（消亡），共12个阶段：

```
长生 → 沐浴 → 冠带 → 临官 → 帝旺 → 衰 → 病 → 死 → 墓 → 绝 → 胎 → 养
```

- **阳干顺行**：甲长生在亥，丙长生在寅，戊长生在寅，庚长生在巳，壬长生在申
- **阴干逆行**：乙长生在午，丁长生在酉，己长生在酉，辛长生在子，癸长生在卯

### 3.2 对得地评分的影响

| 长生位置 | 旧逻辑（藏干） | 新逻辑（长生） | 差异 | 典型命局 |
|----------|----------------|----------------|------|----------|
| **帝旺** | -1（失地） | **+3** | **+4** | 丙午日：午中藏丁己无丙，旧判失地；实际帝旺最强根 |
| **长生** | +1（半得地） | **+2** | **+1** | 壬申日：申中藏壬水中气，旧判半得地；实际长生位 |
| **养** | -1（失地） | **+1** | **+2** | 庚辰日：辰中无庚，旧判失地；实际养位有孕育之气 |
| **病** | -1（失地） | **-2** | **-1** | 乙子日：子中无乙，旧判失地；实际病位更弱 |
| **临官** | +2（得地） | +2 | 0 | 甲寅日：本气藏甲，两者一致 |
| **墓** | +1（半得地） | 0 | -1 | 辛丑日：丑中藏辛中气，旧判半得地；实际墓位入库 |

### 3.3 评分映射表

| 长生位置 | 得分 | 含义 |
|----------|------|------|
| 帝旺 | +3 | 最强根，日主在此地支达到巅峰 |
| 长生 | +2 | 强根，日主获得生命力 |
| 临官 | +2 | 禄位，日主得禄，强力支撑 |
| 冠带 | +1 | 中等支撑 |
| 养 | +1 | 孕育中，有中等支撑 |
| 墓 | 0 | 入库，力量被封存 |
| 胎 | 0 | 初成形，力量很弱 |
| 沐浴 | -1 | 桃花位，日主在此不稳定 |
| 衰 | -1 | 开始衰退 |
| 病 | -2 | 虚弱 |
| 死 | -2 | 无气 |
| 绝 | -2 | 最弱 |

### 3.4 实测影响统计

6个测试用例中，**4个（66%）的得地分数因长生十二宫而改变**：
- 2个提升（壬申日 +1，庚辰日 +2）
- 1个大幅提升（丙午日 +4）
- 1个降低（乙子日 -1）
- 2个不变（甲寅日、辛丑日）

## 四、空亡详解

### 4.1 什么是空亡

空亡（旬空）基于日柱所在的**旬**计算。六十甲子分6旬，每旬10个干支组合，剩余2个地支为空亡：

| 旬 | 空亡地支 |
|----|----------|
| 甲子旬 | 戌、亥 |
| 甲戌旬 | 申、酉 |
| 甲申旬 | 午、未 |
| 甲午旬 | 辰、巳 |
| 甲辰旬 | 寅、卯 |
| 甲寅旬 | 子、丑 |

### 4.2 计算逻辑

```python
def calculate_kongwang(day_tian, day_di):
    # 1. 找到日柱天干地支的索引
    day_tian_idx = TIANGAN.index(day_tian)  # 0-9
    day_di_idx = DIZHI.index(day_di)        # 0-11

    # 2. 计算旬首地支索引
    diff = (day_di_idx - day_tian_idx) % 12

    # 3. 空亡 = 旬首之后第10、11位
    kongwang_1 = DIZHI[(diff + 10) % 12]
    kongwang_2 = DIZHI[(diff + 11) % 12]

    return [kongwang_1, kongwang_2]
```

### 4.3 当前用途

空亡目前作为**排盘模型的补充字段**，用于前端展示，**暂不参与旺衰评分**。

原因：
1. 空亡的地支力量减半规则在不同流派中有争议
2. 主要影响神煞和运势解读，对旺衰的直接影响较小
3. 长生十二宫已能显著提升得地判断的准确性

### 4.4 示例

壬申日 → 壬(8) 申(8) → diff = (8-8)%12 = 0 → 旬首为甲子 → **空亡：戌、亥**

## 五、得局维度详解（三会/三合/刑冲）

### 5.1 合局权重

| 类型 | 权重 | 说明 |
|------|------|------|
| 三会局 | +5 | 最强，三个同方向地支（如申酉戌三会金） |
| 三合局 | +4 | 强，长生+帝旺+墓库（如申子辰三合水） |
| 半三合 | +2 | 中，三合缺一个字，需带中神 |
| 六合 | 暂未纳入 | 化气需结合月令判断，较复杂 |

### 5.2 刑冲削弱

| 类型 | 权重 | 说明 |
|------|------|------|
| 六冲 | -2 | 子午/丑未/寅申/卯酉/辰戌/巳亥 |
| 三刑 | -2 | 寅巳申/丑戌未/子卯 |
| 自刑 | -1 | 辰辰/午午/酉酉/亥亥 |
| 六害 | -1 | 子未/丑午/寅巳/卯辰/申亥/酉戌 |
| 六破 | -1 | 子酉/丑辰/寅亥/卯午/巳申/未戌 |

### 5.3 关键规则

- **合局优先**：参与合局的地支不再单独计算刑冲（避免重复）
- **得势排除**：参与合局的地支不计入得势维度（避免与得局重复计算）
- **三会 > 三合**：同一地支不同时参与两种合局

### 7.2 如何验证排盘一致性

**方法：逐字段对比法**

1. **取标准命局**：选择已知排盘结果的命局（如测测App截图）
2. **系统排盘**：用相同生辰调用 `calculate_bazi()`
3. **逐项对比**：
   - 四柱天干地支 → 必须完全一致
   - 十神 → 必须完全一致
   - 五行数量 → 必须完全一致
   - 纳音 → 必须完全一致
   - 藏干 → 必须完全一致
   - 长生十二宫 → 必须完全一致
   - 空亡 → 必须完全一致
   - 大运起运时间 → 误差 ≤ 1天
4. **边界测试**：测试节气交界日、子时跨日等特殊场景

**自动化验证脚本位置**：`backend/tests/test_changsheng_wangshuai.py`
