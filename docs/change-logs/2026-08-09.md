  - backend/app/services/followup_structured.py
- 主要改动：
  - JSON 结构示例移除 group 块，blocks 只保留 type=keyword，并标注"每个 block 单一维度、≤120字"
  - 硬性JSON渲染约束：每个 subtopic 放 2-4 个 block，每个 block 只讲一个维度（现实走向/应对办法/时间窗口/心态宽慰四选一）；narrative ≤3句、≤120字；同一 subtopic 内所有 block 统一 type=keyword，禁止 group 块

  - 禁止清单新增：禁止同 subtopic 内 block 类型混用、禁止空关键词/group 标题当小标题挂下属段落
  - 新增对照示例：错误写法1（术语堆砌+剧本策略混段）vs 正确写法1（拆两个 keyword block 术语清零）；错误写法2（定心丸 keyword + 精准时间窗口 group）vs 正确写法2（同级统一 keyword block，时间节点各自独立）

- 验证方式：python3 ast.parse 语法校验通过；uvicorn --reload 自动重载；硬刷新浏览器重新追问验证（需阿里云百炼 API 配额充足）

  - group 块展开逻辑按"："拆分 keyword，若 LLM 输出的段落不含"："则用 group title 作 keyword，可能 keyword 不够叙事化
  - 术语黑名单较激进，可能导致 LLM 过度回避、命理缘由完全消失（已保留"最多1个命理词汇+括号释义"的口子）
