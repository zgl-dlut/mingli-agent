# "趣算算"品牌名字体效果增强方案

## 总结

当前"趣算算"品牌名是纯粗体文字（思源黑体圆角 800字重 + 3px字间距），显示效果古板、缺乏品牌质感。通过 CSS 文字渐变填充 + 微投影增强质感，传达"传统稳重+质感"的气质，零依赖、加载快、不影响性能。

## 修改方案

### 方案：CSS 渐变填充 + 微投影 + 装饰下划线

**修改文件：** [index.css](file:///Users/zhangguangling/Downloads/命理推算/mingli-agent/frontend/src/index.css#L83-L109)

#### 1. 深色背景品牌名（Header、LoginPage）

将纯色 `#F8F1E8` 替换为米白→香槟金的渐变填充，加微投影增加浮起感：

```css
.logo-text {
  font-family: "思源黑体圆角", "PingFang SC", system-ui, sans-serif;
  font-weight: 800;
  font-size: 28px;
  letter-spacing: 3px;
  /* 渐变填充：米白→香槟金 */
  background: linear-gradient(135deg, #F8F1E8 0%, #E8D5B8 50%, #C8A67A 100%);
  -webkit-background-clip: text;
  background-clip: text;
  -webkit-text-fill-color: transparent;
  /* 微投影增加层次 */
  filter: drop-shadow(0 2px 3px rgba(0, 0, 0, 0.25));
}
```

**效果说明：**
- `background-clip: text` + `-webkit-text-fill-color: transparent` 实现文字渐变填充
- `filter: drop-shadow` 替代 `text-shadow`（因为 text-fill-color:transparent 会让 text-shadow 失效）
- 渐变从左上到右下：米白(#F8F1E8) → 浅香槟(#E8D5B8) → 香槟金(#C8A67A)，金属质感
- 投影让文字在深棕背景上浮起，增加立体感

#### 2. 浅色背景品牌名（HistoryPanel 侧边栏）

将纯色 `#5A3F37` 替换为深棕→香槟金的渐变填充：

```css
.light-nav .logo-text {
  background: linear-gradient(135deg, #5A3F37 0%, #7A5547 50%, #C8A67A 100%);
  -webkit-background-clip: text;
  background-clip: text;
  -webkit-text-fill-color: transparent;
  filter: drop-shadow(0 1px 2px rgba(122, 85, 71, 0.15));
}
```

**效果说明：**
- 渐变：深棕(#5A3F37) → 主棕(#7A5547) → 香槟金(#C8A67A)，与深色背景版呼应
- 投影更轻（浅色背景上不需要太强投影）

#### 3. 移动端保持不变

```css
@media (max-width: 600px) {
  .logo-text { font-size: 20px; }
}
```

字号缩小即可，渐变和投影自动继承。

#### 4. 不修改的部分
- `font-family`、`font-weight`、`letter-spacing` 保持不变（用户认可思源黑体圆角 + 800字重）
- 不引入外部字体（避免加载性能问题）
- 不加装饰下划线（保持简洁，传统稳重风格不需要多余装饰）

1. `cd mingli-agent/frontend && npm run build` 确认构建通过
2. 浏览器硬刷新，检查三处品牌名显示：
   - Header 导航栏：米白→香槟金渐变，有立体感
   - HistoryPanel 侧边栏：深棕→香槟金渐变，与深色版呼应
   - LoginPage 登录页：与 Header 一致
3. 移动端（<600px）检查字号缩小后渐变是否正常
4. 确认投影不过重，文字清晰可读

## 风险点

- `background-clip: text` 在旧版浏览器（IE）不支持，但项目目标浏览器为现代浏览器，可接受
- `filter: drop-shadow` 性能开销极小，不影响页面加载
- 渐变色值需肉眼确认效果，如太暗可调亮 #E8D5B8 → #ECDCC4
