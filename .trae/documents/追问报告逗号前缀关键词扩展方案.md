# 追问报告逗号前缀关键词扩展方案

## 问题分析

用户反馈：追问报告中"幼小衔接，规矩适应：2030年的规则碰撞"这种格式，"幼小衔接"没有被加粗，只有"规矩适应"被加粗。

### 根因

`_KW_PUNCT`（L271）不含逗号 `，`：
```python
_KW_PUNCT = '（）()【】\\[\\]、·-'
```

`_find_keyword_matches` 正则 `([{_KW_CHARS}{_KW_PUNCT}]+?)\s*{_KW_COLON}` 在遇到逗号时中断匹配，导致"幼小衔接，规矩适应"中只有逗号后的"规矩适应"被识别为关键词。

### 副作用风险

直接把逗号加入 `_KW_PUNCT` 会产生误合并：
- `资金到账期：8月，资金规划：稳健` → "8月，资金规划"会被误识别为一个关键词（因为"8月"含数字，逗号后"资金规划"是另一个独立关键词）

### 区分条件

| 场景 | 逗号前内容 | 期望行为 |
|---|---|---|
| `幼小衔接，规矩适应：描述` | "幼小衔接"是纯中文短语 | 整体作为关键词 `**幼小衔接，规矩适应**：描述` |
| `资金到账期：8月，资金规划：稳健` | "8月"含数字（是前一个关键词的值） | 两个独立关键词，不合并 |

**判断依据**：逗号前的短语如果是纯中文/英文（不含数字），则是关键词短语的一部分；如果含数字（如"8月"），则是前一个关键词的描述值，不应合并。

### 修改点：`_find_keyword_matches` 函数（L296-307）

在匹配到关键词后、添加到 matches 列表前，向前查找"纯中文/英文短语+逗号"前缀，循环扩展关键词范围。

**扩展规则**：
- 正则：`re.search(r'([\u4e00-\u9fa5a-zA-Z]{2,8}[，,])$', prefix_text)`
- 只匹配纯中文/英文短语（2-8字），不含数字 → 避免"8月，"误合并
- 循环处理多个逗号前缀（如"A，B，C：描述" → "A，B，C"）

**伪代码**：
```python
def _find_keyword_matches(line: str) -> list:
    pattern = re.compile(rf'([{_KW_CHARS}{_KW_PUNCT}]+?)\s*{_KW_COLON}')
    matches = []
    for match in pattern.finditer(line):
        keyword = match.group(1)
        if _looks_like_keyword(keyword):
            start = match.start()
            # 向前循环扩展逗号前缀短语（如"幼小衔接，规矩适应"中的"幼小衔接，"）
            # 只扩展纯中文/英文短语，不扩展含数字的（避免"8月，资金规划"误合并）
            extended_start = start
            extended_keyword = keyword
            while True:
                prefix_text = line[:extended_start]
                prefix_match = re.search(r'([\u4e00-\u9fa5a-zA-Z]{2,8}[，,])$', prefix_text)
                if not prefix_match:
                    break
                extended_keyword = prefix_match.group(1) + extended_keyword
                extended_start = prefix_match.start()
            
            matches.append({
                'start': extended_start,
                'end': match.end(),
                'keyword': extended_keyword,
            })
    return matches
```

### 不影响首次报告的保证

首次报告关键词格式为 `**关键词：描述** - 正文`（整体加粗），`_normalize_keyword_line` 中 `_is_inside_bold` 检测到关键词在 `**...**` 内部会 `continue` 跳过。`_find_keyword_matches` 的扩展逻辑只影响"裸关键词"（未加粗的），已加粗的首次报告关键词不受影响。

## 验证用例

| 输入 | 期望识别的关键词 | 期望输出 |
|---|---|---|
| `幼小衔接，规矩适应：2030年的规则碰撞` | `幼小衔接，规矩适应` | `**幼小衔接，规矩适应**：2030年的规则碰撞` |
| `资金到账期：8月，资金规划：稳健` | `资金到账期` + `资金规划`（两个独立） | `**资金到账期**：8月，**资金规划**：稳健` |
| `A，B，C：描述` | `A，B，C`（多逗号扩展） | `**A，B，C**：描述` |
| `2027年，运势分析：描述` | `运势分析`（"2027年"含数字不扩展） | `2027年，**运势分析**：描述` |
| `食神格：兴趣启蒙：描述`（两层冒号嵌套） | 展平为 `兴趣启蒙` | `**兴趣启蒙**：描述` |
| `**日主意象：冬日盆栽** - 正文`（首次报告） | 不处理（已加粗） | 原样保留 |
