# 微信支付接入配置计划

## 现状分析

后端和前端的微信支付代码已经全部就绪，当前处于 mock 模式。需要完成以下配置才能切换到真实支付：

### 已有代码（无需修改）
- 后端 API：`/api/payment/create-wechat-order`、`/api/payment/wechat/callback`、`/api/payment/order-status/{order_id}`
- 后端服务：`wechat_pay_service.py`（JSAPI/H5 下单、回调验签）
- 后端服务：`payment_service.py`（订单创建、积分发放、幂等处理）
- 前端页面：`RechargePage.tsx`（充值档位选择、自定义金额、JSAPI/H5 支付适配）
- 前端工具：`wechat.ts`（微信浏览器检测、wxChooseWXPay 调用）
- 数据库：`orders` 表（订单持久化）

### 当前阻塞原因
1. `.env` 中微信配置全是占位符（`your-wechat-app-id` 等）
2. `wechatpayv3` SDK 未安装（不在 requirements.txt 中）
3. 证书文件不存在（`certs/` 目录未创建）
4. `_wechat_configured()` 返回 False → 所有请求走 mock 模式

## 实施步骤

### 步骤 1：安装 wechatpayv3 SDK

**文件**：`backend/requirements.txt`

添加依赖：
```
wechatpayv3==1.2.5
```

执行安装：
```bash
cd backend && source venv/bin/activate && pip install wechatpayv3
```

### 步骤 2：放置证书文件

**目录**：`backend/certs/`

需要从微信支付商户平台下载以下文件并放入该目录：
- `apiclient_cert.pem` — 商户证书
- `apiclient_key.pem` — 商户私钥

创建目录：
```bash
mkdir -p backend/certs
```

### 步骤 3：填写 .env 微信配置

**文件**：`backend/.env`

将占位符替换为真实值（需要用户提供）：

| 配置项 | 说明 | 获取方式 |
|--------|------|----------|
| `WECHAT_APP_ID` | 微信公众号/小程序 AppID | 微信公众平台 → 开发 → 基本配置 |
| `WECHAT_MCH_ID` | 微信支付商户号 | 微信支付商户平台 → 账户中心 |
| `WECHAT_API_KEY` | APIv3 密钥 | 商户平台 → 账户中心 → API安全 → 设置APIv3密钥 |
| `WECHAT_SERIAL_NO` | 证书序列号 | 商户平台 → 账户中心 → API安全 → 查看证书序列号 |
| `WECHAT_NOTIFY_URL` | 支付回调地址 | 已配置为 `https://shisuansuan.com/api/payment/wechat/callback` |

### 步骤 4：验证配置生效

1. 重启后端服务（uvicorn --reload 需要手动重启才能加载 .env 变更）
2. 前端访问充值页面，选择金额点击充值
3. 后端日志应显示 `[payment] 微信支付配置已就绪` 而非 mock 模式日志
4. 微信内应弹出 JSAPI 支付窗口，微信外应跳转 H5 支付页面

### 步骤 5：验证回调

1. 确保 `https://shisuansuan.com/api/payment/wechat/callback` 可从外网访问
2. 微信支付成功后，回调会触发 `update_order_paid` 发放积分
3. 检查后端日志确认回调验签通过

---

## 注意事项

1. **证书安全**：`certs/` 目录已在 `.gitignore` 中，不会被提交到 git
2. **回调地址**：当前配置为 `https://shisuansuan.com/api/payment/wechat/callback`，确保 Nginx 已正确代理该路径
3. **JSAPI vs H5**：
   - 微信内浏览器（MicroMessenger UA）→ 自动使用 JSAPI 支付（需要 openid）
   - 普通浏览器 → 使用 H5 支付
   - 当前代码已自动判断，无需额外配置
4. **JSAPI 支付需要 openid**：如果用户在微信内打开，需要获取用户的 openid。当前代码中 `openid` 参数是可选的，如果未传入会返回 400 错误。需要确认前端是否已实现获取 openid 的逻辑。
5. **重启后端**：修改 .env 后必须手动重启 uvicorn 服务，`--reload` 不监视 .env 文件
