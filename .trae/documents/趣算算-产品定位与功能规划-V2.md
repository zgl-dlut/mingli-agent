## 1. 产品定位

### 1.1 一句话

**趣算算 = 一个能用命盘解释你和他的 AI 陪伴产品。**

用户带着情绪来（我怎么了、他到底怎么想、我该不该做），我们给的不是安慰，而是**有依据的解释 + 可执行的建议**。

### 1.2 三个「不是」

- 不是排盘工具：排盘只是输入，交付的是解读与陪伴
- 不是通用聊天机器人：每句话都要落在命盘依据上，不说放之四海皆准的空话
- 不是心理咨询 / 医疗：不做诊断、不承诺疗效，危机场景只做转介

### 1.3 差异化

| 竞品常见做法 | 趣算算的做法 |
|---|---|
| 星座/塔罗：人人都能套上 | 八字命盘：十神、大运、流年，可验证、可追溯 |
| 通用陪伴 App：空壳角色扮演 | 命盘 + 人格资料，人格有依据 |
| 纯命理工具：只给结论不给情绪 | 两段式：先给框架建立预期，再给深度解读 |

## 2. 目标用户与场景

### 2.1 用户画像

- 主体：25–35 岁，女性为主，一二线 + 新一线
- 特征：处在情感或职业的选择期，愿意为「确定性」付费，习惯订阅与按次解锁并行
- 动机：不是猎奇，是**想被理解**，且想要一个说得通的理由

### 2.2 三个核心场景（JTBD）

| 场景 | 用户心里的话 | 产品承接 |
|---|---|---|
| 自我确认 | 我今年到底怎么样？我是什么样的人？ | 今日日运（免费）、月运 / 年报 |
| 关系困惑 | 他到底怎么想？我们合不合适？ | **关系视角解读（B 方案）**、对话提问 |
| 决策焦虑 | 要不要跳槽 / 分手 / 搬家？ | 对话 + 两段式深度解读，给时间窗与行动建议 |

### 2.3 情绪水位

用户进入产品时情绪水位偏高（焦虑、委屈、犹豫）。因此：
- 首屏必须先给情绪价值（免费日运、免费分析框架）
- 付费动作一律放在「用户已经获得价值之后」
- **禁止在低谷情绪下弹付费窗**（沿用需求文档 6.4 红线）

## 3. 产品结构

### 3.1 导航（沿用已实现）

底部三 Tab：**今日 / 对话 / 我的**，430px App 容器，端隔离（仅 App 端可见专属功能）。

### 3.2 四层能力

```
① 认识自己   今日日运（免费）→ 命盘 → 月运 → 年报
② 理解关系   关系视角解读（B）：我 vs TA 的关系说明书
③ 获得陪伴   对话咨询：免费框架 → 积分解锁深度解读（异步生成）
④ 资产账本   档案管理 / 积分钱包 / 报告中心 / 反馈记录
```

### 3.3 页面地图

| Tab | 页面 | 状态 |
|---|---|---|
| 今日 | 今日页（四段切换） | 本期改造 |
| 今日 | 月运试看页 / 月运正文页 | 本期新增 |
| 今日 | 年报正文页 | 本期新增 |
| 对话 | 对话页（欢迎引导 + 星盘选人 + 深度解读开关） | 已实现 |
| 对话 | 深度解读页（大纲 → 生成中 → 正文） | 已实现 |
| 对话 | 关系视角解读页（合盘大纲 + 正文） | 本期新增 |
| 我的 | 我的页 / 档案管理 / 档案编辑（含「与我的关系」） | 已实现 + 改造 |
| 我的 | 星盘详情页（命盘 / 流盘 / 合盘三页签） | 本期新增 |
| 我的 | 更多解读页（命盘维度逐条解读 + AI 解读入口 + 分享） | 本期新增 |

| 我的 | 报告中心 | 本期新增 |

**不设独立「关系中心」，今日页也不放关系入口**。关系是档案的属性，在**添加档案时**选择「与我的关系」（本人 / 恋人 / 夫妻 / 亲子 / 朋友 / 同事）。单人星盘与合盘共用对话顶部的「⊕ 星盘 · 小玲 ▾」一个入口，在弹层内用页签切换；未来新增紫微、塔罗等盘种，也并入同一弹层的页签，不再新增入口。

1. **对话页顶部「⊕ 星盘 · 小玲 ▾」（唯一入口）**：弹层含「单人 / 合盘」页签。单人 → 选人看星盘详情；合盘 → 先列已有关系，再提供「新建合盘」选 2 人（默认当前档案为我方），未设关系时就地补选。
2. **星盘详情页底部「⇄ 与 TA 合盘」**：从某人星盘直接发起与当前用户的合盘，等价于在弹层里选好 2 人。

## 5. 消费路径与闭环

### 5.1 积分经济

| 项目 | 积分 | 说明 |
|---|---|---|
| 新用户赠送 | 240 | 首读 160 + 追问 40 × 2，覆盖一次完整体验 |
| 首次命盘报告 | 160 | 建档即扣，已实现 |
| 追问提问（H5/PC） | 40 | 已实现 |
| 深度解读解锁（App） | 60 | 提问免费出框架，解锁才扣 |
| 月运 | 80 | 本期新增 |
| 年报 | 160 | 本期新增 |
| 关系视角解读 | 120 | 本期新增，会员 8 折 |
| 充值 | 1 元 = 10 分 | 已实现 |
| 会员月卡 | ¥25 | 月运/年报免费 + 深度解读 10 次 |
| 会员季卡 | ¥58 | 同上，折合 ¥19.3/月 |
| 会员年卡 | ¥178 | 同上，折合 ¥14.8/月（主推） |

### 5.2 免费额度（钩子）

- 今日日运：完全免费，每日刷新
- 每份报告：总评 + 1 个维度免费，其余锁定
- 对话提问：App 端免费出分析框架
- 命格关键词：免费，可分享

### 5.3 五步闭环

| 步骤 | 用户动作 | 付费点 | 得到什么 | 回流钩子 |
|---|---|---|---|---|
| ① 进来 | 打开 App 看今日日运 | 无 | 今日吉凶、宜忌、五行 | 明天再来 / 分享命格关键词 |
| ② 建档 | 添加档案，生成首次报告 | 160 分（新人赠送覆盖） | 命盘 + 首读全文 | 追问入口、月运预告 |
| ③ 复购 | 对话提问「我今年事业？」 | 免费框架 → 60 分解锁 | 深度解读正文 + 分析依据 | 新问题、历史深度解读回看 |
| ④ 周期 | 切到本月 / 本年 | 80 / 160 分 | 月运 / 年报 | 报告中心沉淀、下月更新 |
| ⑤ 关系 | 选对方档案做关系解读 | 120 分 | 关系说明书 + 相处建议 | 引导为对方建档（再触发 ②） |

### 5.4 闭环图

```
            免费日运（每日）
                  │  D1 留存
                  ▼
        建档 → 首读 160 ──► 首读完成
                  │              │
                  │              ▼
                  │        对话提问（免费框架）
                  │              │ 解锁率
                  │              ▼
                  │        深度解读 60 ──► 正文 + 依据
                  │              │              │
                  ▼              ▼              ▼
            月运 80 ──► 年报 160 ──► 报告中心
                  │              │
                  ▼              ▼
            关系解读 120 ──► 为对方建档（回到 ②）
                  │
                  ▼
            分享 / 邀请 → 新用户 → 回到 ①
```

### 5.5 用户为什么会回来（四类驱动）

| 驱动 | 触发 | 承接页面 |
|---|---|---|
| 时间 | 每天 0 点日运刷新、每月 1 号月运更新、流年节点 | 今日页 |
| 事件 | 用户遇到具体问题（吵架、面试、签约） | 对话页 |
| 关系 | 对方档案有新解读、关系阶段变化 | 关系解读页 |
| 资产 | 已解锁报告沉淀、消费记录 | 报告中心 / 我的 |

### 5.6 关键设计原则

1. **先给价值再收钱**：框架、总评、1 个维度免费
2. **不在情绪低谷弹付费**：识别负面情绪时降级付费引导
3. **解锁即到账**：后台生成，离开页面也能完成
4. **同一份内容只收一次钱**：服务端持久化解锁状态，换端/刷新不重复扣
5. **每个付费点都有明确交付物**：不卖"更多可能"，卖"这篇报告"

### 模块 04 我的 · 资产与权益（8 屏）

入口：底部 Tab「我的」。行为：我的首页 → 我的档案 → 点某人进**星盘详情**，顶部页签「命盘 / 流盘 / 合盘」：

- **命盘**：四柱主表（十神·藏干·支神·纳音·空亡·地势·神煞·地支关系）→ 五行旺衰 → **AI 基础解读**（「Ai 解读」开半弹层、「更多解读」进逐条列表）→ **个性化追问卡**（完整解读将展开 3 条 + 「和 AI 聊聊」回对话）
