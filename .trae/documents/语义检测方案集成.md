### 核心局限

* 枚举式检测是"打地鼠"，LLM 换说法就绕过

* 维度覆盖检测只覆盖"换组"场景，其他场景（如"赔偿""入职"）的答非所问无法检测

* 无法检测"开篇说不换组、正文讲换新领导"这种语义层矛盾（除非关键词正好匹配）

## Proposed Changes

### 方案选择：sentence-transformers + 语义相似度

**为什么选这个方案**：

* 最轻量：bge-small-zh-v1.5 约100MB，CPU推理50-200ms/次，适合阿里云轻量级服务器

* 中文支持好：BAAI 专门做中文模型

* 集成简单：pip install + 10行代码

* 用户要求"先用简单方案实现"

**能覆盖的场景**：

* ✅ 答非所问（用户问题 vs subtopic title 相似度低 = 不相关）

* ✅ 开篇与正文不相关（opening.verdict vs subtopic narrative 相似度低）

**不能覆盖的场景**（需后续迭代）：

* ❌ 开篇与正文矛盾（"不换组" vs "换了新领导"——相似度高但语义相反，需 NLI 模型）

* ❌ 同义词对立（"拿不到A但能拿B"——需 NLI 或 LLM 审查）

### 改动2：新增语义检测模块

**文件**：`backend/app/services/semantic_checker.py`（新建）

**功能**：

* 单例加载 BAAI/bge-small-zh-v1.5 模型（避免重复加载）

* `check_relevance(question, subtopic_title)` → 返回相似度分数

* `check_consistency(opening_verdict, subtopic_narrative)` → 返回相似度分数

* 模型首次运行从 HuggingFace 下载（\~100MB），国内可配置镜像站

**核心代码结构**：

```python
from sentence_transformers import SentenceTransformer, util
import threading

_model = None
_lock = threading.Lock()

def get_model():
    global _model
    if _model is None:
        with _lock:
            if _model is None:
                _model = SentenceTransformer("BAAI/bge-small-zh-v1.5")
    return _model

def compute_similarity(text_a, text_b):
    model = get_model()
    emb_a = model.encode(text_a, convert_to_tensor=True)
    emb_b = model.encode(text_b, convert_to_tensor=True)
    return float(util.cos_sim(emb_a, emb_b))

def check_relevance(question, subtopic_titles):
    """检测用户问题与各subtopic title的相关性，返回低于阈值的项"""
    model = get_model()
    q_emb = model.encode(question, convert_to_tensor=True)
    title_embs = model.encode(subtopic_titles, convert_to_tensor=True)
    scores = util.cos_sim(q_emb, title_embs)
    return scores

def check_consistency(opening_verdict, subtopic_narratives):
    """检测开篇结论与各subtopic narrative的一致性，返回低于阈值的项"""
    model = get_model()
    o_emb = model.encode(opening_verdict, convert_to_tensor=True)
    n_embs = model.encode(subtopic_narratives, convert_to_tensor=True)
    scores = util.cos_sim(o_emb, n_embs)
    return scores
```

## Assumptions & Decisions

1. **模型选择**：BAAI/bge-small-zh-v1.5（中文，\~100MB，512维，CPU推理50-200ms/次）
2. **不替代现有8类检测**：作为第九类补充，与枚举检测互补
3. **阈值初步设定**：答非所问0.3、开篇一致性0.4，后续根据效果调整
4. **模型单例加载**：避免每次检测重复加载，首次加载约2-3秒
5. **可开关**：通过 SEMANTIC\_CHECK\_ENABLED 控制，模型加载失败时不阻塞主流程
6. **HuggingFace 下载**：国内可能需要配置镜像站（`HF_ENDPOINT=https://hf-mirror.com`）
7. **PyTorch 依赖**：CPU版约200MB，需确认服务器磁盘空间

## 局限性说明（诚实告知）

| 矛盾类型     | 语义相似度能否覆盖 | 说明                                 |
| -------- | --------- | ---------------------------------- |
| 答非所问     | ✅ 能       | 用户问题 vs subtopic title 相似度低        |
| 开篇与正文不相关 | ✅ 能       | opening vs subtopic narrative 相似度低 |
| 开篇与正文矛盾  | ❌ 不能      | "不换组" vs "换了领导"相似度高但相反，需 NLI       |
| 同义词对立    | ❌ 不能      | "拿不到A但能拿B"需 NLI 或 LLM 审查           |
| 术语/凶年/干支 | ❌ 不需要     | 现有枚举检测已覆盖                          |

**后续迭代方向**：

* 如果语义相似度初步验证有效 → 可升级到中文 NLI 模型（如 IDEA-CCNL/Erlangshen-Roberta-330M-NLI）做矛盾检测

* 如果 NLI 模型效果不好 → 可用 qwen-flash 做 LLM 审查（零新依赖，但每次多一次调用）
