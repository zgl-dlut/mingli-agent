# 购买积分页面支持自定义充值

## 摘要
当前充值页面仅支持6个固定档位（160/200/400/800/1000/2000积分），用户无法自定义充值金额。需要在保留固定档位快捷选择的基础上，新增自定义积分输入功能。

## 当前架构分析

### 数据流
1. 前端 RechargePage.tsx / RechargeModal.tsx → 用户选择固定档位 → 调用 `paymentApi.createWechatOrder({points, pay_type})`
2. 后端 payment.py `create_wechat_order` → 调用 `payment_service.create_order(db, user_id, points, "wechat")`
3. payment_service.py `create_order` → **校验 `points not in POINTS_PACKAGES` 则报错** → 创建订单
4. 支付成功后 `update_order_paid` → `add_points` 发放积分

### 关键约束
- **后端 `payment_service.py` 第84行**：`if points not in POINTS_PACKAGES: raise BusinessError("无效的充值档位")` — 这是阻止自定义金额的核心限制
- **`POINTS_PACKAGES` 字典**（第14-24行）：固定映射 9 个档位 {40:4.0, 80:8.0, 120:12.0, 160:16.0, 200:20.0, 400:40.0, 800:80.0, 1000:100.0, 2000:200.0}
- **兑换比例**：1元 = 10积分（amount = points / 10）
- **前端 API** `payment.ts`：已接受任意 `points: int`，无需改动
- **后端 API** `payment.py`：`CreateWechatOrderRequest` 已接受任意 `points: int`，无需改动
- **Order 模型**：`points: int` + `amount: float`，灵活足够

## 改动方案

### 1. 后端：payment_service.py — 放开档位限制
- **文件**：`backend/app/services/payment_service.py`
- **改动**：
  - `create_order()` 函数：删除 `if points not in POINTS_PACKAGES` 校验
  - 改为动态计算金额：`amount = round(points / 10, 1)`（1元=10积分）
  - 新增最小/最大限制：`MIN_RECHARGE_POINTS = 10`，`MAX_RECHARGE_POINTS = 10000`
  - 保留 `POINTS_PACKAGES` 字典供后台展示参考，不再做强制校验

### 2. 前端：RechargePage.tsx — 新增自定义输入
- **文件**：`frontend/src/pages/RechargePage.tsx`
- **改动**：
  - 保留6个固定档位按钮作为快捷选择
  - 在档位按钮下方新增「自定义积分」输入框（数字输入，placeholder="输入积分数量"）
  - 新增 state：`customPoints`（字符串）和 `isCustomMode`（布尔）
  - 用户点击固定档位 → `isCustomMode=false`，`selectedPoints=档位积分`
  - 用户在输入框中输入 → `isCustomMode=true`，`selectedPoints=输入值`
  - 充值按钮文案动态显示：`充值 X 积分 (¥X/10)`
  - 输入校验：10~10000之间的整数，不合法时按钮禁用
  - 输入框样式与整体暖咖配色统一（`#a7876f` 边框聚焦色）

### 3. 前端：RechargeModal.tsx — 同步新增自定义输入
- **文件**：`frontend/src/components/RechargeModal.tsx`
- **改动**：与 RechargePage.tsx 完全一致的自定义输入逻辑

## 不需要改动的文件
- `frontend/src/api/payment.ts` — 已接受任意 points
- `backend/app/api/payment.py` — 已接受任意 points
- `backend/app/models/order.py` — 字段灵活足够

## 假设与决策
- 兑换比例不变：1元 = 10积分
- 自定义积分范围：10~10000（最低1元，最高1000元）
- 自定义输入仅支持整数积分
- 固定档位保留作为快捷选择，不删除
- 前端输入校验：非数字/小于10/大于10000/非整数 → 按钮禁用并显示提示

## 验证步骤
1. `npm run build` 构建通过
2. 后端重启，用 curl 测试自定义积分创建订单：
   ```
   curl -X POST http://localhost:8000/api/payment/create-wechat-order \
     -H "Content-Type: application/json" \
     -H "Authorization: Bearer <token>" \
     -d '{"points": 150, "pay_type": "h5"}'
   ```
   预期返回 `{"order_id": ..., "points": 150, "amount": 15.0, "mock": true}`
3. 测试边界值：points=10（通过）、points=10000（通过）、points=9（拒绝）、points=10001（拒绝）
4. 前端验证：输入自定义积分 → 按钮文案更新 → 充值流程正常
5. 前端验证：点击固定档位 → 自定义输入框清空 → 正常切换
