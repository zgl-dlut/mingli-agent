# 修复报告渲染问题

## 任务概述

1. **`###` 标题符号直接显示为文本**：模型输出的 Markdown `###` 没有被渲染成标题，直接展示为 `###` 字符
2. **对话框标题下的命格箴言消失**：之前添加的命格箴言展示可能被覆盖

## 根因分析

### 问题1：`###` 未渲染

可能原因：模型输出的 `###` 后面没有空格（如 `###标题` 而非 `### 标题`），导致 ReactMarkdown 无法识别为标题。需要在 prompt 中明确要求 `###` 后必须有空格。

也可能原因：`parseSSEStream` 的修改导致 Markdown 格式被破坏（之前改为按 `\n\n` 分割，可能把 `### 标题\n\n内容` 错误切割）。

### 问题2：命格箴言消失

代码检查确认 `Chat.tsx` 第 283-284 行命格箴言代码仍在。可能是 `baziResult` 数据问题或渲染条件不满足。需要实际验证。

## 实施方案

### 修改1：`prompt_builder.py` + `skill_prompts.py` — 标题格式规范

在所有 prompt 的排版指令中，明确要求：
```
- `##` 和 `###` 后面必须有一个空格再写标题文字
- 不要输出"开篇承接"、"全局核心总纲"、"分模块解答"等结构标签名称，直接用内容相关的标题
```

### 修改2：`Chat.tsx` — 验证命格箴言展示

确认第 283-284 行代码正确，检查 `baziResult` 在对话视图下是否有值。

### 修改3：`parseSSEStream` — 确保 Markdown 格式完整性

检查流式解析器是否破坏了 `###` 标题格式。

## 涉及文件

| 文件 | 说明 |
|------|------|
| `backend/app/services/prompt_builder.py` | 首次解读 prompt 排版指令 |
| `backend/app/services/skill_prompts.py` | 追问 prompt 排版指令 |
| `frontend/src/pages/Chat.tsx` | 命格箴言展示 + SSE 解析器 |
