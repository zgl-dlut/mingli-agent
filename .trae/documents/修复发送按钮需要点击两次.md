# 修复追问发送按钮需要点击两次的问题

## 任务概述

用户反馈：每次发送追问都需要发送/点击两次才能成功。

## 根因分析

`Chat.tsx` 第 436 行：
```tsx
onKeyDown={(e) => e.key === 'Enter' && handleSend()}
```

问题：缺少 `e.preventDefault()`。Enter 键按下时：
1. 触发 `handleSend()` — 第一次发送
2. 浏览器默认行为（如 input 在 form 内会触发 submit）或移动端键盘的重复 keydown 事件 — 可能导致第二次触发

此外，`handleSend` 虽然有 `isGenerating` 守卫，但 `setIsGenerating(true)` 是异步的（React state 更新不是立即生效），在极短时间内第二次调用可能绕过守卫。

## 实施方案

**文件**：`frontend/src/pages/Chat.tsx`

第 436 行，添加 `e.preventDefault()`：
```tsx
onKeyDown={(e) => { if (e.key === 'Enter') { e.preventDefault(); handleSend() } }}
```
