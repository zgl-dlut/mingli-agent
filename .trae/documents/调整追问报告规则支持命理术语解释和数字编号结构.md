# 调整追问报告规则：支持命理术语解释和数字编号结构

## 背景与目标

用户提供了一个"比较满意的回复"样本，该样本与当前追问模板规则存在三个核心冲突：
1. **命理术语**：样本大量使用命理术语（申子辰三合水局、财星破印、壬丙相冲）且做了通俗解释，但当前规则"严格禁止命理术语作为关键词"
2. **子问题内部结构**：样本用"数字编号 + 小标题 + 多行正文"结构，当前规则只有 `**关键词**：描述` 单行格式
3. **内容深度**：样本有深入的命理分析（三合局、天干相冲）和强烈的故事性，当前规则偏向精简

用户确认的调整方向：
- 命理术语：**允许使用 + 必须紧跟通俗解释**
- 内部结构：**两种格式都允许**（单行 + 数字编号）
- 强调标记：**移除【】用加粗**（保持现状）

**约束**：只调整追问模板（GENERAL_FOLLOWUP_PROMPT），不影晩首次报告模板。

## 修改方案

### 修改1：命理术语规则（skill_prompts.py line 892）

**当前**：
```
**严格禁止使用任何命理专业术语作为关键词，包括包含命理术语的复合词**（如"印星护体"含"印星"、"火土帮身"含"火土"——一律禁止）。命理术语黑名单（包括但不限于）：用神、忌神、火土、食伤、印星、比劫、七杀、官杀、十神、五行、印比、劫财、伤官、禄神、帮身、护体、财旺身弱、身弱、财旺、土旺、羊刃、魁罡、华盖、桃花、驿马、空亡、刑冲合害、食神制杀、印星护体、禄神帮身、杀重用印、伤官见杀、财坏印、劫财合财。关键词必须用日常大白话，像一个给朋友讲的小结论，且直接贴合用户问题的关切点（时间、金额、选择、对象等），让零基础用户一眼看懂
```

**改为**：
```
**允许使用命理术语，但必须紧跟通俗解释**。命理术语（如申子辰三合水局、财星破印、壬丙相冲、帮身担财等）可以出现在关键词和正文中，但每次出现必须紧跟人话翻译，让零基础用户看得懂。解释方式可选：
- 关键词中：`**背锅与名誉危机（财星破印）**：描述` 或 `**财星破印=因利益冲突导致职位受威胁**：描述`
- 正文中：先说术语再用"="或"也就是"解释，如"这叫'财星破印'，现实中往往代表因巨大的利益冲突、资金压力，导致职位、名誉受威胁"
**禁止只甩术语不解释，禁止术语与解释分离超过一行**。保留命理推演的专业深度，但确保每处术语都有大白话落地
```

### 修改2：子问题内部结构（skill_prompts.py line 890-891）

**当前**：
```
6. **子问题内部结构**（每个子问题内部根据内容动态抽象出关键词作为子标题，**关键词段落不超过3个**（上限仅作封顶，不需要写满3个），关键词需贴合大标题提问问题）：
   - **格式**：`**关键词短语**：描述内容`（只加粗关键词，冒号在加粗外，描述内容不加粗，在同一行）
```

**改为**：
```
6. **子问题内部结构**（每个子问题内部根据内容复杂度选择结构，**关键词段落不超过3个**（上限仅作封顶，不需要写满3个））：
   - **格式A（单行，适合简单结论）**：`**关键词**：描述内容`（只加粗关键词，冒号在加粗外，描述内容不加粗，在同一行）
   - **格式B（数字编号+多行，适合复杂命理分析）**：
     ```
     1. **小标题**（可含命理术语+括号解释）
     正文段落，详细解释命理逻辑和现实对应（命理术语必须解释）
     
     2. **小标题**
     正文段落
     ```
   - **选择原则**：简单结论用格式A；需要深入分析命理组合（如三合局、相冲、大运交替）用格式B
   - 两种格式可在同一报告的不同子问题中混用，根据内容复杂度灵活选择
```
