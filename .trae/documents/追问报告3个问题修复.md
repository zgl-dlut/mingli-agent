# 追问报告3个问题修复

## Summary

3个问题都针对追问报告：
1. 前端发送追问后显示2条问题（后端去重已生效，前端addMessage导致）
2. 子问题关键词仍为【】格式（skill_prompts已修复，但format_normalizer和LLM残留）
3. 子问题需要"一二三"中文序号，总结部分不包含序号

## Current State Analysis

### 问题1：前端2条问题
- Chat.tsx第589行 `addMessage(person.id, 'user', question)` 乐观更新
- Chat.tsx第616行 `fetchMessages` 从后端拉取（覆盖）
- 后端去重已生效（刷新后只有1条），但addMessage + fetchMessages时序交叉可能导致临时显示2条
- addMessage去重检查allChats，不检查Zustand messages状态

### 问题2：【】格式残留
- skill_prompts.py中【】已清除（只剩第66行禁止指令和第709行免责声明）
- format_normalizer.py第249行 `_KW_PUNCT = '（）()【】\\[\\]、·-'` 包含【】，用于关键词匹配
- LLM可能仍输出【】格式（prompt修改后需要重启后端生效）
- format_normalizer.py没有【】→`**关键词：**`的转换逻辑

### 问题3：子问题序号
- skill_prompts.py第24行已有`## 一、`中文数字序号指令
- 第69行已有`禁止在总结部分添加中文数字序号`
- LLM可能未严格遵循

## Proposed Changes

### 修改1：移除addMessage乐观更新

**文件**：`frontend/src/pages/Chat.tsx`
**位置**：第588-589行
**修改内容**：移除addMessage调用，用户消息只在fetchMessages后从后端拉取显示

将：
```typescript
// 乐观更新：立即显示用户消息（后端已保存，fetchMessages会同步覆盖）
addMessage(person.id, 'user', question)
```

改为：
```typescript
// 不再本地addMessage：后端已去重保存，fetchMessages从DB拉取（以DB为准，避免重复）
```

**为什么**：后端去重已确保只有1条用户消息，fetchMessages只拉取1条。移除addMessage彻底消除重复风险。用户在SSE流期间看到"AI正在回复..."的currentMessage提示，不会觉得消息丢失。

### 修改2：format_normalizer添加【】转换

**文件**：`backend/app/services/format_normalizer.py`
**修改内容**：在格式归一化时，将【关键词】格式转换为`**关键词：**`格式

在normalize_output函数中添加预处理步骤：
```python
# 将【关键词】格式转换为 **关键词：** 格式
content = re.sub(r'【([^】]+)】', r'**\1：**', content)
```

**为什么**：LLM可能仍输出【】格式（即使prompt已禁止）。format_normalizer作为后处理层，确保最终输出统一为`**关键词：**`格式。这是健壮性保障，不依赖LLM遵循prompt。

### 修改3：强化子问题序号指令

**文件**：`backend/app/services/skill_prompts.py`
**修改内容**：在FORMAT_DIRECTIVE中更强调子问题序号格式

在第24行后添加：
```
- **序号强制要求**：子问题标题必须使用中文数字序号（一、二、三...），禁止使用阿拉伯数字（1. 2. 3.）或无序号
- **总结部分不添加序号**：总结标题使用 `## 💡 总结：动态标题` 格式，不使用 `## 四、总结` 等序号
```

**为什么**：已有指令但LLM未严格遵循，需要更强调。

### 修改4：重启后端

**操作**：重启后端服务，确保skill_prompts.py的修改生效

## Assumptions & Decisions

1. **移除addMessage是核心方案**：后端去重已生效，前端不需要乐观更新。fetchMessages从DB拉取是唯一数据源
2. **format_normalizer做后处理保障**：不依赖LLM遵循prompt，确保最终输出格式统一
3. **子问题序号已有指令**：只需更强调，不需要大改
4. **需要重启后端**：skill_prompts.py修改后--reload可能未完全生效
