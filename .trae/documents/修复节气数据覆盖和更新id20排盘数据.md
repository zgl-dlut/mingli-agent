# 修复节气数据覆盖问题 + 更新 id=20 排盘数据

## 问题现状

### 节气数据覆盖缺口
`PRECALCULATED_JIEQI` 实际覆盖年份：
- **1988-1993**（6年）
- **2023-2045**（23年）
- **缺失：1994-2022（整整29年！）**

寿星公式回退只返回日期（无时分秒），精度仅"天"级别，导致：
- 起运年龄偏差 0.1-0.5 岁
- 大运年份偏移 1 年
- 年柱可能判断错误（立春前后出生）

### 其他硬编码数据表状态
| 数据表 | 覆盖范围 | 状态 |
|--------|---------|------|
| PRECALCULATED_JIEQI | 1988-1993, 2023-2045 |  缺失1994-2022 |
| NAYIN（纳音表） | 60甲子全覆盖 | ✅ 无缺失 |
| DIZHI_CANGGAN（藏干表） | 12地支全覆盖 | ✅ 无缺失 |
| SHISHEN（十神） | 程序逻辑生成 | ✅ 无缺失 |
| TIANGAN/DIZHI | 10天干/12地支 | ✅ 无缺失 |

**结论：唯一有年份缺失风险的是节气数据。**

## 解决方案

### 方案选择：引入 sxwl 库替代硬编码

[sxwl](https://github.com/xaminxan/sxwl)（寿星万年历 Python 版）：
- 基于 VSOP87 行星扰动理论 + ELP2000 月球历表
- 精度：秒级（与《中国天文年历》误差 < 2秒）
- 跨度：公元前4713年 ~ 公元9999年
- 纯 Python 实现，无重量级科学计算依赖
- MIT 许可证

**优势**：彻底消除年份缺失问题，无需逐年手动补充节气数据。

### Step 2: 修改 solar_term_time 函数
**文件**: `backend/app/services/bazi_service.py` 第847-897行

修改逻辑：
1. 优先从 PRECALCULATED_JIEQI 缓存获取（避免重复计算）
2. 缓存 miss 时使用 sxwl 库计算（秒级精度，覆盖所有年份）
3. 删除寿星公式回退逻辑（不再需要）

需要做的适配：
- sxwl 返回的是 `(name, jd)` 列表，需要按 term_index 映射
- 代码中 term_index 顺序：0=小寒, 1=大寒, 2=立春, ..., 23=冬至
- sxwl 的节气顺序可能不同，需要建立映射表

```python
# 节气名称到 term_index 的映射
JIEQI_NAME_TO_INDEX = {
    "小寒": 0, "大寒": 1, "立春": 2, "雨水": 3,
    "惊蛰": 4, "春分": 5, "清明": 6, "谷雨": 7,
    "立夏": 8, "小满": 9, "芒种": 10, "夏至": 11,
    "小暑": 12, "大暑": 13, "立秋": 14, "处暑": 15,
    "白露": 16, "秋分": 17, "寒露": 18, "霜降": 19,
    "立冬": 20, "小雪": 21, "大雪": 22, "冬至": 23,
}

def solar_term_time(year: int, term_index: int) -> datetime:
    """计算指定年份的24节气时间（精确到秒）"""
    # 优先从预计算表获取（缓存）
    if year in PRECALCULATED_JIEQI and term_index in PRECALCULATED_JIEQI[year]:
        return PRECALCULATED_JIEQI[year][term_index]
    
    # 使用 sxwl 库计算（秒级精度，覆盖所有年份）
    from sxwl import calendar
    from sxwl.eph0 import fromJD
    
    jq_list = calendar.SSQ.get_all_jq(year)
    # 建立 term_index -> datetime 映射
    index_to_dt = {}
    for name, jd in jq_list:
        idx = JIEQI_NAME_TO_INDEX.get(name)
        if idx is not None:
            index_to_dt[idx] = fromJD(jd + 2451545)
    
    if term_index in index_to_dt:
        return index_to_dt[term_index]
    
    # 极端情况：sxwl 也失败，返回一个合理的默认值
    raise ValueError(f"无法计算 {year} 年第 {term_index} 个节气")
```
