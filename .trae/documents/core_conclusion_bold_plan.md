# 核心结论加粗修复方案

## 问题分析

### 现象
对话解读报告中，开头的核心结论部分（"核心结论：xxx"）**没有加粗**，以普通文本显示。

### 根因

**双重不匹配**导致核心结论丢失加粗效果：

#### 1. Prompt 格式与前端正则不匹配

**Prompt 规定的格式**（skill_prompts.py 第 56-57 行、第 276-278 行）：
```
**核心结论：2027年上半年入职最佳**——您命局喜火，2026-2027年火旺是事业黄金期...
```

**前端正则**（Chat.tsx 第 39 行）：
```js
html = html.replace(/^\*\*(核心结论：.+)\*\*$/gm, '<p><strong>$1</strong></p>')
```

**冲突点**：正则使用 `^\*\*...\*\*$`（行首^ + 行尾$），要求整行必须以 `**` 开头且以 `**` 结尾。但 Prompt 格式在 `**...**` 后面还有 `——命理逻辑解释` 文本，导致正则**无法匹配**。

#### 2. 兜底正则也不匹配

前端第 41 行兜底正则：
```js
html = html.replace(/^(核心结论：.+)$/gm, '<p><strong>$1</strong></p>')
```
这个要求"核心结论："开头的行独占一行。但 AI 生成时经常把核心结论和解释文本混在同一行，也不匹配。

#### 3. 最终 `**` 被清除

前端第 51 行：`html.replace(/\*\*/g, '')` 会清除所有未被匹配的 `**` 标记，导致核心结论最终以普通文本显示。

## 修改方案

### 1. 修改前端 Chat.tsx — 修复正则匹配（核心修复）

**文件**：`frontend/src/pages/Chat.tsx`

**修改内容**：重写 `markdownToHtml` 函数中的核心结论处理逻辑

将现有的 6 个核心结论正则（第 31-41 行）替换为更健壮的处理：

```js
// ========== 核心结论处理（在关键词格式之前处理） ==========
// 1. 匹配 **核心结论：xxx** 后跟解释文本的格式（最常见）
//    **核心结论：xxx**——解释文本... → 只加粗核心结论部分
html = html.replace(
  /\*\*(核心结论：[^*]+)\*\*(.+)/gm, 
  '<p><strong>$1</strong>$2</p>'
)
// 2. 匹配 **核心结论：xxx** 独占一行的格式
html = html.replace(
  /^\*\*(核心结论：[^*]+)\*\*$/gm, 
  '<p><strong>$1</strong></p>'
)
// 3. 匹配 核心结论：xxx 独占一行（无前缀，兜底）
html = html.replace(
  /^(核心结论：.+)$/gm, 
  '<p><strong>$1</strong></p>'
)
// 4. 匹配 #### 核心结论：xxx 标题格式
html = html.replace(
  /^#+\s*(核心结论：.+)$/gm, 
  '<p><strong>$1</strong></p>'
)
```

关键改进：
- 用 `[^*]+` 替代 `.` 确保只匹配到第一个 `**` 为止
- 用 `(.+)` 捕获 `**` 后面的解释文本，保留不加粗
- 多个正则按优先级排序，先匹配最常见的格式

### 2. 修改 Prompt — 统一核心结论格式

**文件**：`backend/app/services/skill_prompts.py`

**修改位置**：
- 第 51-57 行（FORMAT_DIRECTIVE 核心结论规则）
- 第 275-278 行（skill prompt 输出框架第2步）

**修改内容**：统一核心结论的格式规范

```
修改前：
格式：`**核心结论：完整结论描述**`（加粗，结论描述可以是一句话，包含核心观点和命理逻辑，不限字数）
示例：`**核心结论：2027年上半年入职最佳**——您命局喜火...`

修改后：
格式：`**核心结论：结论描述**` + `——命理逻辑解释`（结论部分加粗，解释部分不加粗）
要求：核心结论部分必须单独用**包裹，结论描述精炼有力（不超过30字），命理逻辑解释用破折号连接
示例：`**核心结论：2027年上半年入职最佳**——您命局喜火，2026-2027年火旺是事业黄金期...`
```

### 3. 修改 CSS — 确保核心结论样式突出

**文件**：`frontend/src/index.css`

**修改位置**：第 338-342 行

当前 CSS：
```css
.report-content strong {
  color: #1a1a1a;
  font-weight: 700;
  font-size: 1em;
}
```

为核心结论增加特殊样式（更大字号、特殊背景）：
```css
.report-content > p:first-of-type strong,
.report-content strong:has-text("核心结论") {
  font-size: 1.05em;
  font-weight: 800;
  color: #1a1a1a;
  background: linear-gradient(135deg, #fffbeb, #fef3c7);
  padding: 0.15rem 0.4rem;
  border-radius: 0.25rem;
  border-left: 3px solid #f59e0b;
}
```

## 风险评估

- **低风险**：所有修改都是向后兼容的，前端正则新增了更多匹配模式，不会破坏现有格式
- **可验证**：修改后可以通过实际对话测试验证核心结论是否正确加粗
