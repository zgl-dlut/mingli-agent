# 修复追问报告：问题拆解 + 结构优化

## 任务概述

用户追问"26年内部转岗还是跳槽发展更好，内部转岗的话是朋友或者老婆介绍的岗位还是我自己找的岗位"后，AI 回复存在两个问题：
1. 没有把用户提问拆解成多个子问题逐一解答
2. 输出结构不对，不是期望的固定结构

## 根因分析

### 问题1：未拆解用户问题

`skill_prompts.py` 中 career 专项 prompt（第 63-78 行）虽然有"分模块逐一解答客户问题"的指令，但：
- 用户问题是以一段连续文本传入的（`{user_question}`）
- prompt 中没有**显式要求模型先列出问题清单再逐一解答**
- 模型倾向于把整段问题当作一个整体来回答，而不是拆解

### 问题2：结构标签仍被输出

虽然之前在 `FORMAT_DIRECTIVE` 中加了"严禁输出结构标签名称"的指令，但：
- 各专项 prompt 模板内部仍使用了 `### 1. 开篇承接`、`### 2. 全局核心总纲` 等标签
- 模型会模仿 prompt 中的结构标签格式
- 需要在 prompt 中用**示例**来展示期望的输出格式，而非用结构标签来描述结构

## 实施方案

### 修改1：`skill_prompts.py` — 所有 prompt 模板（4个专项 + 1个通用）

**改动A**：在"用户本次全部提问"部分，增加显式的问题拆解指令：

```
## 用户本次全部提问
{user_question}

**重要：你必须先将用户提问拆解为多个具体子问题，然后用 ### 标题逐一解答每个子问题。**
```

**改动B**：将 prompt 中的结构描述改为**输出示例**，让模型通过示例学习格式，而非通过结构标签：

把现有的：
```
### 1. 开篇承接
确认时空背景...
### 2. 全局核心总纲
一句话定整体...
### 3. 分模块逐一解答客户问题
...
```

改为：
```
## 输出结构要求（按以下顺序输出，不要输出编号和结构标签名称）

第一段：用2-3句话承接时空背景和命局格局，定调本次推演。

第二段：一句话总结整体策略方向。

后续：将用户问题拆解为多个子问题，每个子问题用 ### 三级标题（标题写具体问题内容，如"### 内部转岗运势分析"），每个子问题内部按四段式展开（结论→命理逻辑→时间细节→行动建议）。

最后一段：综合决策建议。
```

**改动C**：对所有 5 个 prompt（career/wealth/marriage/health/general）统一执行改动A和改动B。

## 验证步骤

   - 问题被拆解为多个子问题（内部转岗 vs 跳槽；朋友介绍 vs 自己找）
