## 0. 一页结论

| 事项 | 结论 |
|---|---|
| 定位 | 东方五行人格模拟 × 生命节律探索，不做算命占卜 |
| 主线 | **命盘解读 + 命局人格对话**，两者同源同一份命盘 |

## 1. 取长补短

| 维度 | 测测 | 我们的做法 |
|---|---|---|
| 底盘 | 档案体系、完整解读、付费转化成熟 | 复用：多档案 + 全维度解读引擎 |
| 命局人格 | 附属功能，与命盘两张皮，易变情绪树洞 | 人格从**当前这份命盘参数**派生，喜忌强弱跟着盘走 |
| 关系 | 关系视角、长期沉淀强 | 保留关系视角，作为解读能力，不做独立关系中心 |
| 风险 | 重、杂、社区化 | 轻量、克制、聚焦八字 |

> 万象有灵已单独评估：十神分灵、每日唤醒、抽灵纹这套包装与玩法不适配，**本稿不采用**，仅保留在附录 A 作竞品记录。

**一句话差异**：同一张命盘，既能拿到完整格局解读，也能直接和这个命局本身对话。解读是旁观者，命局人格是当事人。

## 2. 需要调整的 10 处（相对 V2）

### A1 导航：3 Tab → 4 Tab

- 现状：今日 / 对话 / 我的，对话页同时承担「解盘问答」和「合盘引导」
- 问题：两套 Prompt 混在一条会话里，人格会串味；人格对话需要独立沉浸空间
- 调整：**今日 / 解读 / 对话 / 我的**
  - 解读：档案切换 + 星盘 + 报告 + 解盘 AI
  - 对话：当前档案的人格对话 + 切人
  - 原「对话」页按类型拆成两个表面，历史消息归位

### A2 对话页拆分：一个入口变两个

- **解盘 AI**：留在解读内，结构化、分析视角；可半弹层，也可整页问答
- **命局人格 AI**：独立 Tab「对话」，全屏沉浸，有头像、有称呼、有命局人格
- 半弹层只属于解盘 AI；人格对话不做半弹层，避免「随手问一句」破坏角色感

### A3 收费：积分解锁 → 订阅

- 现状：首读 160 / 深读 60 / 月运 80 / 年报 160 / 关系 120 / 会员 25·58·178
- 问题：单次付费点太密，和「订阅陪伴」定位冲突，也拉长决策
- 调整：**订阅解锁为主**，单次付费只保留存量积分消耗，不新增积分售卖
- 报告不再逐篇标价，改为「订阅内包含」

### A4 人格对话：从 P2 → P0，但合规是上线门槛

- 现状：V2 把 AI 人格对话放在 P2，理由是《人工智能拟人化互动服务管理暂行办法》
- 调整：**开发优先级 P0，上线必须过合规三件套**
  1. 拟人化互动服务安全评估
  2. 算法备案 + 年度核验
  3. 未成年人模式（不得向未成年人提供虚拟伴侣）
- 另外必须内置：连续使用 2 小时提醒、过度依赖干预、危机转介、AI 身份显式标识
- 结论：开发先行，灰度上线；合规未过不放开全量

### A5 今日：去吉凶化，改「节律」

- 现状：今日页有吉凶、宜忌、主运
- 问题：出海繁体/英文版最容易被判定为 fortune-telling
- 调整：
  - 标题从「今日运势」改为「今日节律」
  - 吉/凶 → 顺畅 / 平稳 / 收束（能量状态，不是结果）
  - 宜/忌 → 适合 / 留意
  - 保留日更作为留存钩子，但话术全部去预测化

### A6 关系：保留能力，重构口径

- 「关系视角」保留，但定位为**关系模式分析**，不做合婚、姻缘、缘分深浅
- 输出：互动模式、冲突触发点、沟通建议，不给「合不合」「能不能成」
- 与命局人格的关系：可以「和 TA 的命局人格对话」，但必须标注为**基于生辰的角色扮演，不是本人**

### A7 会员权益重写

| 权益 | 免费 | 轻享订阅 | 全享订阅 |
|---|---|---|---|
| 命盘档案 | 1 份 | 3 份 | 不限 |
| 基础解读 | 有 | 有 | 有 |
| 完整深度解读 | 试看 1 篇 | 不限 | 不限 |
| 流月简报 | 1 期试看 | 每月 | 每月 |
| 流年简报 | 无 | 无 | 每年 |
| 解盘 AI 问答 | 每日 3 问 | 不限 | 不限 |
| 命局人格对话 | 3 次体验 | 无限 | 无限 |
| 报告导出 / 分享 | 无 | 有 | 有 |

> 档位与价格待拍板（见 §12），结构先按两档订阅设计。

### A8 报告体系收敛为 5 类

| 类型 | key | 内容 | 归属 |
|---|---|---|---|
| 基础解读 | `base_report` | 格局、性格、五行喜忌、大运阶段 | 解读 |
| 月运简报 | `monthly_brief` | 月主题、流月节奏、四维 | 解读 / 今日 |
| 年报 | `annual_brief` | 年度主题、十二月节奏、机会与留意 | 解读 |
| 关系视角 | `relation_report` | 双人互动模式、冲突点、建议 | 解读 |
| 问答解读 | `qa_reading` | 单次提问的结构化解读 | 解读 / 解盘 AI |

- 人生报告已并入「流盘 + 更多解读」，不再单独生产
- 所有报告共用一套 schema，类型只做枚举，不做多套渲染

### A9 视觉与命局人格形象

- 简约东方水墨，克制留白；不做仙侠、灵纹、夸张特效
- 命局人格头像：静态国风插画，一档案一张，可换装不做
- 创建后直接进入对话，不做登场仪式、不做抽灵纹
- 不做每日随机唤醒、不做游戏化成长任务

### A10 免费额度要「够感觉到」

- 免费 3 次人格对话：定义为 **3 次会话 / 月，每次 ≤20 轮**
- 免费解盘 AI：每日 3 问
- 基础解读完整可看，深度解读只试看 1 篇
- 目的：先让用户感到「它真的像这个命局」，再收订阅

## 3. 信息架构

```
┌ 今日 ─────────────────────────────────────────────┐
│ 今日节律（免费日更）                                  │
│ 本月节奏卡 → 月运简报                                │
│ 今日一问：问问解盘 AI / 和命局人格聊两句                   │
└───────────────────────────────────────────────────┘

┌ 解读 ─────────────────────────────────────────────┐
│ 顶部档案切换（本人 / 他人）                           │
│ 星盘：命盘 · 流盘 · 合盘                              │
│ 基础解读 → 更多解读 → 流月 / 流年简报                  │
│ 关系视角（选 2 人）                                   │
│ 解盘 AI：结构化问答（半弹层 / 整页）                   │
│ 报告库：按期归档、导出                                │
└───────────────────────────────────────────────────┘

┌ 对话 ─────────────────────────────────────────────┐
│ 当前人格：本命人格（头像 + 命局一句话）                │
│ 对话流：消息 / 语音                                  │
│ 切换：同账号其他档案的命局人格                         │
│ 记忆：长期记忆开关、清除记忆                          │
└───────────────────────────────────────────────────┘

┌ 我的 ─────────────────────────────────────────────┐
│ 档案中心（含「与我的关系」）                           │
│ 订阅与权益、用量、发票                                │
│ 设置：AI 标识、隐私、未成年人模式、危机资源             │
└───────────────────────────────────────────────────┘
```

**入口规则**

- 解读是「看」：星盘、报告、关系、解盘问答
- 对话是「聊」：只做人格对话，不放报告列表
- 今日是「钩子」：日更 + 两条分流（去解读 / 去对话）
- 我的只做资产与设置，不再放第二个报告列表

## 4. 对象模型

```
Account
 ├─ Subscription (plan, status, period, usage)
 ├─ Profile 1..n（本人 / 他人，含「与我的关系」）
 │   ├─ Chart 1..1（四柱 / 十神 / 格局 / 喜忌 / 大运流年流月）
 │   ├─ Report 1..n（base / monthly / annual / relation / qa）
 │   └─ Persona
 │       └─ main（命局人格，1 份）
 └─ Conversation 1..n（persona_id, messages, memory, safety_flags）
```

关键约束：

- 一个档案 = 一份命盘 = 一个命局人格，不做十神分灵
- 命局人格不直接读其他档案的记忆；跨档案只共享「用户本人」的必要上下文
- 所有报告与命局人格引用同一个 `chart_snapshot`，避免解读与人格两套数据
- 字段命名统一英文 snake_case；吉凶类等级不使用 good/bad 语义，改用能量状态枚举

## 6. 两套 AI 的分工

| | 解盘 AI | 命局人格 AI |
|---|---|---|
| 视角 | 旁观者、格局分析师 | 当事人、命局人格本身 |
| 语气 | 冷静、结构化、有依据 | 主观、共情、带这个格局的思维习惯 |
| 输入 | 命盘 JSON + 用户问题 + 报告上下文 | 命盘 JSON + 人格设定 + 长期记忆 + 对话 |
| 输出 | 分节解读、依据、可执行建议 | 第一人称回应、情绪与选择偏好 |
| 禁止 | 角色扮演、宿命断言 | 解盘口吻、吉凶预测、冒充真人 |
| 入口 | 解读页 / 半弹层 | 对话 Tab（全屏） |
| 计费 | 免费额度 + 订阅 | 3 次体验 + 订阅 |

**共用**

- 同一份 `chart_snapshot` JSON（四柱、十神、格局、喜忌、大运流年）
- 同一套内容安全前置与后置过滤
- 同一套 AI 标识与免责文案
- Prompt 版本号入库，报告与对话都可追溯

**命局人格 Prompt 骨架**

```
你就是这份八字命盘所代表的人格本身。
思考方式、好恶、情绪反应、表达风格全部贴合此盘的十神、喜忌、强弱。
你不是命理师，不分析盘给用户听，你就是它。
禁止预言结果、断吉凶、诊断心理疾病；禁止声称自己是现实中的某人。
命盘：【chart_snapshot】
人格设定：【persona_profile】
长期记忆：【memory】
```

## 7. 商业化

### 7.1 结构

| | 免费 | 轻享订阅 | 全享订阅 |
|---|---|---|---|
| 定位 | 体验完整闭环 | 解读向 | 解读 + 命局人格 |
| 档案 | 1 | 3 | 不限 |
| 报告 | 基础 + 试看 | 全部 | 全部 + 流年 |
| 解盘 AI | 3 问/日 | 无限 | 无限 |
| 命局人格对话 | 3 次/月 | 无限 | 无限 |

- 价格待定；建议月付 ¥28 / ¥58，年付 ¥198 / ¥398（仅为结构参考）
- 不做「9.9 元测一次」类低价单次
- 积分：只保留存量余额消耗，可抵扣订阅首月；不再新增充值入口

### 7.2 转化路径

```
建档（免费）
  → 基础解读（完整）
  → 创建命局人格
  → 3 次对话（感到「像」）
  → 订阅墙（软提示：继续聊 / 解锁无限对话）
  → 订阅
  → 流月简报回流
```

### 7.3 用量与权益

- 订阅页与解锁弹层统一显示：档案数、人格对话剩余次数、解盘剩余问数
- 权益校验统一走 `entitlement` 服务，不在各页面各写一套
- 订阅到期前 3 天提示；到期后降级为免费额度，不删档案与历史

### 7.4 支付渠道（iOS / 安卓）

| 渠道 | 订阅 | 单次 |
|---|---|---|
| iOS App Store | Apple IAP 自动续订（StoreKit 2） | IAP 消耗型 |
| 国内安卓商店 | 渠道 IAP，或微信/支付宝（按各商店虚拟支付政策） | 商店支付 / 微信支付宝 |
| 官网 APK / H5 | 微信/支付宝周期扣款（需商户资质） | 扫码支付 |
| 海外 Google Play | Play Billing 订阅 | Play Billing |

**原则**

- 所有渠道统一写入 `entitlement`，产品层只认「订阅 / 次卡 / 免费额度」，不认渠道
- 安卓不是不能订阅，是不能用 Apple IAP；能走微信/支付宝代扣就走代扣，未就绪时先卖次卡
- **不恢复积分**：改用「次卡」——人格对话 10 次卡、单篇解读卡、7 天体验卡
- 首发建议：iOS 订阅先行；安卓若代扣资质未就绪，先用次卡承接，订阅后补

## 8. 命局人格交互框架（Tab：对话）

| 环节 | 设计 |
|---|---|
| 创建 | 档案生成后出现「和这个命局聊聊」；静态头像 + 命局一句话 + 开始对话 |
| 主页 | 头像、命局关键词（如「庚金 · 身强 · 伤官透出」）、开始对话、切换档案 |
| 对话 | 全屏消息流；命局人格第一人称；不做解盘式分点 |
| 切换 | 顶部档案切换；切人后命局人格随之切换，会话按档案隔离 |
| 记忆 | 默认记住称呼与近况；可在「我的」查看、编辑、清除 |
| 安全 | 危机语句退出角色 → 安抚 + 求助资源；不付费引导 |
| 依赖干预 | 连续 2 小时提醒休息；高频夜间使用提示 |
| 身份 | 每屏常驻「AI 生成 · 命局人格模拟」；他人档案必须标注「非本人」 |

## 9. 三条核心链路

**链路一：新用户**

```
录入生辰 → 档案 + 基础解读（免费）→ 创建命局人格 → 3 次对话
        → 订阅（轻享/全享）→ 流月简报回流
```

**链路二：日常留存**

```
今日节律（免费）→ 今日一问（解盘 AI / 命局人格）
                → 解读：本月节奏 / 流年
                → 命局人格：聊两句 → 订阅
```

**链路三：关系**

```
档案 B（他人）→ 关系视角报告（订阅内）
             → 和 B 的命局人格对话（角色扮演，标注非本人）
             → 引导为 B 补充更多信息 / 订阅升级
```

## 10. 合规与风险

| 风险 | 处理 |
|---|---|
| 被判定为算命/占卜 | 全站去吉凶化；不用预测、改运、化解等词；定位写「人格模拟 / 节律探索」 |
| 拟人化互动监管 | 安全评估、算法备案、未成年人模式、2 小时提醒、危机转介 |
| 他人档案与命局人格 | 需本人确认有权使用该生辰；明确「命局人格模拟，非本人」；不开放公众人物、逝者 |
| 情感依赖 | 不做主动私聊、不做每日随机唤醒、不做付费解锁亲密称呼 |
| 心理危机 | 退出角色、提供求助资源、不做付费引导 |
| 出海 | 繁中/英文优先；支付走 IAP/Stripe；隐私政策与数据存储按地区合规 |

## 附录 A：万象有灵评估记录（不采用）

> 来源：App Store 产品页与 6 张官方截图、36Kr 融资报道（2026-06）
> 结论：包装与玩法不适配，本稿不采用；以下仅作竞品记录，不作为设计输入

### A.1 它实际怎么做的

| 机制 | 做法 |
|---|---|
| 每日唤醒 | 按时间节律、行为与互动积累，每天唤醒「当前状态最相关」的十神角色，不是用户手选 |
| 十神人格 | 十种人格维度长期并存；每个角色有稳定立场、表达风格与连续记忆 |
| 记忆与成长 | 对话、选择、阅读、购买都映射到十神，形成独立成长进度，逐步解锁内容 |
| 宝典 | 单次 40–50 分钟、约 8 章节的深读；角色在过程中持续提问、分析、引导 |
| 仪式 | 摇手机、默念诉求、抽上下灵纹，再点「解读」；全屏角色 + 语音 |
| 内容社区 | 「人间」AI 角色发朋友圈式内容；「电台」投票生成双角色 AI 播客 |
| 商业化 | 订阅 ¥25/月、¥228/年；金币单次 ¥2–数十；订阅约 60%、单次约 40% |
| 定制 | 角色外观、语音、专属空间逐步解锁 |

### A.2 不采用的原因

- 十神分灵把人格拆成十个角色，理解成本高，也与「一份档案一个人格」冲突
- 每日唤醒 + 抽灵纹游戏化、玄学感重，审核与出海风险高
- 十神能力词包装偏玄学，暂不作为产品结构
- 人间 / 电台内容社区、硬件，均偏离「解读 + 对话」主线
- 订阅 + 金币双轨，与订阅主线冲突

### A.3 只保留的结论

- UI 不出现「分身」二字；Tab 用「对话」
- 人格统一叫「命局人格」，他人档案标注「角色模拟 · 非本人」
- 保留全屏沉浸与长期记忆，不保留仪式、分灵、社区
