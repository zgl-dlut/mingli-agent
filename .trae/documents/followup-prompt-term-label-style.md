# 追问报告术语带出方式调整方案

## 一、调整目标

将追问报告术语带出方式从"**术语在前 + 括号解释意思**"（如"偏官（七杀，代表外部压力）"）调整为"**大白话现象在前 + 括号术语标签**"（如"外部压力较大（七杀）"）。

**核心约束**：
- 大白话叙事是主干，占 90% 以上
- 必要术语只作"命理出处标签"以括号形式点缀，不超过 10%
- 括号里**只放术语名**，不在括号里解释意思（主干大白话已说清现象）
- 小白读主干就懂，括号术语是给懂行的人看的出处，可跳过

## 六、风险点

1. **黑名单调整风险**：从"禁止十神名直接出现"放宽为"允许括号标签带出"，模型可能过度使用术语。**对策**：保留术语密度约束（一整段最多1-2个标签），并在禁止清单和对照示例中明确错误形式。

2. **模型遵循度风险**：qwen-plus 对 prompt 多重要求的遵循度历史表现一般，可能仍出现"术语在前+括号解释"形式。**对策**：在对照示例中用明确的❌/✅对照，让模型直观看到正确形式。

3. **与首次报告风格不一致风险**：追问报告调整为"大白话+术语标签"后，首次报告仍是"术语+括号解释"风格，两套报告风格割裂。**对策**：本次只动追问报告（用户明确范围），首次报告后续单独统一。

4. **memory 中旧规则冲突**：project_memory.md 中记录的"追问报告命理术语解释规则：术语必须融入 narrative/paragraphs 句子中，用括号、'='或'也就是'紧跟解释自然流出"与本次调整方向相反。**对策**：本次调整是对旧规则的更新，执行后需同步更新 memory 记录。
