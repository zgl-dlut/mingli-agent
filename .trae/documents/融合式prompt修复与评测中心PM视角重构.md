# 融合式 Prompt 修复 + 评测中心 PM 视角重构

## 问题 1：融合式 Prompt 未生效

### 根因分析

prompt 中有**两处矛盾指令**，LLM 选择了更容易的括号标签式：

| 位置 | 内容 | 状态 |
|------|------|------|
| 第 165 行（角色定义） | `术语融入句子主干，术语后紧跟大白话解释` | ✅ 融合式 |
| 第 315 行（术语管控） | `✅ 可接受（括号标签式）：大白话+括号术语——"外部压力较大（七杀）"` | ❌ 给了 LLM 退路 |

LLM 看到"括号标签式是可接受的"，就默认用了更简单的括号方式。

### 修复方案

**文件**: `backend/app/services/followup_structured.py`

1. **第 315 行**：将"✅ 可接受（括号标签式）"改为"❌ 禁止（括号标签式）"，明确括号标签式不合格
2. **第 165 行**：强化角色定义中的融合式要求，去掉括号示例
3. **第 318 行**：判断标准改为"术语出现后，小白能否不依赖括号就读懂？不能→不合格"

具体改动：
- 第 315 行：`✅ 可接受（括号标签式）` → `❌ 禁止（括号标签式）：大白话+括号术语——"外部压力较大（七杀）"；括号标签打断叙事节奏，不合格`
- 第 165 行：去掉括号示例，改为纯融合式描述
- 第 318 行：判断标准收紧

## 问题 2：评测中心需要 PM 视角重构

### 用户画像
一个想转行做 AI 产品经理的产品经理，对评测模块的定义、闭环、报告形态完全不知道。期望**一眼看完就能理解 AI 产品的评测方法论**。

### 当前问题
- 评测中心只展示数字指标（检测准确率、通过率等），没有解释"为什么测这些"、"怎么测的"、"结果意味着什么"
- 没有评测方法论的说明
- 没有评测闭环的可视化（从用例设计 → 执行 → 结果 → 改进）
- 数据来源（实验室 vs 生产）虽然加了标签，但没有解释两者的区别和关系

### 重构方案

**文件**: `frontend/src/pages/EvalDashboard.tsx`

#### Tab 1: 评测概览 → 改为「评测方法论」

面向 PM 的教育性内容，包含：

1. **评测体系全景图**（视觉化）
   ```
   ┌─────────────────────────────────────────────────┐
   │                 评测体系                          │
   │                                                  │
   │  ┌──────────┐    ┌──────────┐    ┌──────────  │
   │  │ 实验室评测 │ →  │ 生产监控  │ →  │ 持续改进  │  │
   │  │ (预定义用例)│    │ (真实用户) │    │ (Prompt优化)│  │
   │  └──────────┘    └──────────┘    └──────────┘  │
   │       ↓                ↓                ↓        │
   │  结构检查          智能采样          问题定位      │
   │  叙事检查          LLM深度评测       Prompt修复    │
   │  命盘检查          趋势监控          回归验证      │
   └─────────────────────────────────────────────────┘
   ```

2. **三层检测体系说明**（卡片式）
   - 第一层：规则检测（100% 覆盖，零成本）→ 术语黑名单、干支纪时写法
   - 第二层：轻量指标（100% 覆盖，低成本）→ 字数、block 数量、生成耗时
   - 第三层：LLM 深度评测（智能抽样）→ 高风险必检 + 异常触发 + 5% 随机

3. **评测指标字典**（表格）
   | 指标 | 含义 | 怎么算 | 合格线 |
   |------|------|--------|--------|
   | 检测准确率 | 预期与实际匹配的比例 | 预期失败+实际失败=通过 | ≥80% |
   | 通过率 | 通过硬性检查的比例 | 0 违规 = 通过 | ≥60% |
   | L2 格式完成率 | JSON 符合 Schema 的比例 | 解析成功 = 通过 | ≥90% |
   | 任务完成率 | L1×L2×L3×L4 综合完成率 | 四层检查都通过 | ≥70% |

4. **数据来源说明**
   - 实验室评测：预定义用例，有预期结果，用于回归测试
   - 生产监控：真实用户报告，智能采样，用于发现未知问题

5. **核心指标卡片**（保留现有，但加说明）

#### Tab 2: 评测结果 → 保持不变（增加数据来源筛选已在上一轮完成）

#### Tab 3: 评测集内容 → 保持不变

### 新增文件
