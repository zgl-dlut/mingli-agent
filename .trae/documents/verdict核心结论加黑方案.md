# 开篇 verdict 核心结论加黑与多重总结

## 问题
当前 verdict prompt：`"核心结论(可选)。一句话定调，可内联**加粗**"`

两个问题：
1. "一句话定调"限制为单一结论，用户希望可多重总结（多个要点分句）
2. LLM 输出 `核心结论：**后面内容**`，"核心结论"四字没加黑，后面全黑

## 修复
改 `followup_structured.py` L57 的 verdict 描述：

```
"verdict": "核心结论(可选)。可包含多重总结要点（多个分句），不固定一句话，不强制以'核心结论'开头；若用'核心结论'开头，'核心结论'四字必须用**加粗**（如**核心结论**：...）；后面内容只加粗关键时间节点/结论词，禁止整段全加粗"
```

## 不改动
- 前端 OpeningView：renderInline 已支持 ** 加粗，不动
- opening 的 lead：不动

## 验证
- 生成追问，确认开篇"核心结论"加黑，后面不全黑
