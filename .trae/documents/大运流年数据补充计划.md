### 6. 数据格式对齐

**问题**：`eval_chart_dataset.json` 使用中文 key，但实际系统输出可能使用英文 key

**解决方案**：在 `chart_checker.py` 中添加字段映射

```python
FIELD_MAPPING = {
    "干支": "ganzhi",
    "起始年龄": "start_age",
    "起始年份": "start_year",
    "天干": "tiangan",
    "地支": "dizhi",
    "五行": "wuxing",
    "用神标记": "yongshen",
    "忌神标记": "jishen",
    "判断": "judge",
    "理由": "reason"
}

def normalize_chart_data(data: dict, use_chinese: bool = True) -> dict:
    """统一数据格式，支持中英文 key 互转"""
    if use_chinese:
        return {FIELD_MAPPING.get(k, k): v for k, v in data.items()}
    else:
        reverse_mapping = {v: k for k, v in FIELD_MAPPING.items()}
        return {reverse_mapping.get(k, k): v for k, v in data.items()}
```

### 7. 增强排盘正确性检查器

**文件**：`backend/app/services/eval/chart_checker.py`

**新增检查项**：

```python
def check_chart_correctness(generated: dict, expected: dict) -> List[Dict]:
    violations = []
    
    # 现有检查项（1-7）...
    
    # 8. 大运详细信息检查
    gen_dayun_list = generated.get("大运列表", [])
    exp_dayun_list = expected.get("大运列表", [])
    for i, exp_dayun in enumerate(exp_dayun_list):
        if i < len(gen_dayun_list):
            gen_dayun = gen_dayun_list[i]
            # 检查五行属性
            if exp_dayun.get("天干五行") and gen_dayun.get("天干五行") != exp_dayun["天干五行"]:
                violations.append({
                    "type": "大运天干五行错误",
                    "position": i,
                    "expected": exp_dayun["天干五行"],
                    "actual": gen_dayun.get("天干五行"),
                    "location": f"大运列表[{i}].天干五行"
                })
            # 检查用忌神标记
            if exp_dayun.get("用神标记") and gen_dayun.get("用神标记") != exp_dayun["用神标记"]:
                violations.append({
                    "type": "大运用神标记错误",
                    "position": i,
                    "expected": exp_dayun["用神标记"],
                    "actual": gen_dayun.get("用神标记"),
                    "location": f"大运列表[{i}].用神标记"
                })
    
    # 9. 流年详细信息检查
    gen_liunian = generated.get("重点流年", [])
    exp_liunian = expected.get("流年", {})
    for year_str, exp_ln in exp_liunian.items():
        year = int(year_str)
        gen_ln = next((ln for ln in gen_liunian if ln.get("year") == year), None)
        if gen_ln:
            # 检查五行属性
            if exp_ln.get("天干五行") and gen_ln.get("天干五行") != exp_ln["天干五行"]:
                violations.append({
                    "type": "流年天干五行错误",
                    "year": year,
                    "expected": exp_ln["天干五行"],
                    "actual": gen_ln.get("天干五行"),
                    "location": f"流年.{year}.天干五行"
                })
            # 检查吉凶判断
            if exp_ln.get("流年判断") and gen_ln.get("judge") != exp_ln["流年判断"]:
                violations.append({
                    "type": "流年判断错误",
                    "year": year,
                    "expected": exp_ln["流年判断"],
                    "actual": gen_ln.get("judge"),
                    "location": f"流年.{year}.判断"
                })
    
    # 10. 流月详细信息检查
    gen_liuyue = generated.get("流月数据", {})
    exp_liuyue = expected.get("流月_2026", {})
    for month_key, exp_ly in exp_liuyue.items():
        gen_ly = gen_liuyue.get(month_key)
        if gen_ly:
            # 检查吉凶判断
            if exp_ly.get("吉凶") and gen_ly.get("吉凶") != exp_ly["吉凶"]:
                violations.append({
                    "type": "流月吉凶错误",
                    "month": month_key,
                    "expected": exp_ly["吉凶"],
                    "actual": gen_ly.get("吉凶"),
                    "location": f"流月.{month_key}.吉凶"
                })
    
    return violations
```

## Assumptions & Decisions

### 假设

1. **排盘系统输出格式**：假设 `dayun_liunian_skill.py` 的输出已经包含详细的五行、用忌神、交互分析等信息，只是当前 `eval_chart_dataset.json` 没有完整记录

2. **数据准确性**：假设用户提供的命盘标准数据（从截图提取）是准确的，可以作为评测基准

3. **字段映射**：假设中英文 key 可以通过映射表统一，不影响检查逻辑

### 决策

1. **数据格式选择**：保持 `eval_chart_dataset.json` 使用中文 key，在检查器中添加映射逻辑
   - 理由：中文 key 更直观，便于手工校验和维护

2. **详细程度**：补充完整的五行、用忌神、交互分析、判断理由
   - 理由：这些信息是排盘系统的核心输出，必须验证其正确性

3. **重点流年范围**：选择2021-2030年作为重点流年
   - 理由：覆盖当前大运（2021-2031）的主要年份，且具有实际咨询价值

4. **流月数据范围**：仅补充2026年流月数据
   - 理由：2026年是当前年份，最具参考价值；其他年份流月数据可后续扩展

## Risk Points

1. **数据准确性风险**：手工录入的标准数据可能存在错误
   - 缓解措施：使用多个权威排盘工具交叉验证

2. **排盘系统变更风险**：排盘算法更新可能导致标准数据失效
   - 缓解措施：标准数据集版本化管理，记录对应的排盘算法版本

3. **性能风险**：补充大量详细数据后，评测耗时增加
   - 缓解措施：分层次评测，核心字段优先验证

4. **维护成本风险**：详细数据需要持续维护
