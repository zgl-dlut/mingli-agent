# 追问报告：关键结论强制附带排盘依据

## 目标
所有带时间/吉凶判断的结论，必须在narrative中自然融入命盘数据依据（大运干支、流年干支、十神、用神/忌神等），让用户能验证结论不是LLM胡说。

**不改JSON结构、不改前端展示**，仅通过prompt强化+后端检测实现。

## 当前问题
- prompt已有"月份建议必须引用流月干支+十神"（第306行），但只覆盖月份建议
- 其他关键结论（如"27年火土帮身""丁丑大运合身""丙午流年忌神"）没有强制要求附带排盘依据
- LLM经常只说结论不给依据，用户无法判断是LLM编造还是命盘真实数据

## 修改方案

### 1. Prompt强化：新增"关键结论必须附带排盘依据"硬约束

**文件**: `followup_structured.py` 第306行之后

**新增规则**（在现有"月份建议必须引用流月干支+十神"之后）：

```
- **关键结论必须附带排盘依据（硬约束，违反即不合格）**：所有涉及时间判断、吉凶判断、用神/忌神、大运/流年影响的结论，narrative中必须自然融入命盘数据作为依据，禁止只抛结论不给命盘来源。
  - ✅正确："你现在走的**丁丑大运**，天干丁壬相合（合身），就像公司主动把资源和职位绑到你手上"
  - ❌错误："大运把机会绑到你身上"（没提哪个大运、什么关系）
  - ✅正确："今年**丙午流年火旺**，外部压力明显加大，新岗位带来的不是轻松红利而是更密集的考核"
  - ❌错误："今年压力很大"（没提流年干支和五行）
  - **必须引用的场景**：
    - 流年吉凶判断 → 必须提流年干支+五行（如"丙午流年火旺"）
    - 大运影响 → 必须提大运干支+与日主关系（如"丁丑大运，丁壬合身"）
    - 用神/忌神 → 必须提具体五行（如"火是用神，火旺帮身"）
    - 月份建议 → 必须提流月干支+十神（已有规则）
  - **融入方式**：命盘数据自然融入大白话主干，不要括号堆砌。如"今年丙午火旺，外部压力明显"而非"今年（丙午流年，火旺为忌神）外部压力明显"
```

### 2. 新增检测函数：`_detect_conclusion_without_bazi_basis`

**文件**: `followup_structured.py`，在 `_detect_month_without_liuyue_basis` 之后

**检测逻辑**：
1. 提取所有 narrative 文本
2. 查找含以下类型结论的句子：
   - 流年判断（如"今年""27年""丙午年" + 吉凶词）
   - 大运影响（如"大运""这步运" + 影响描述）
   - 用神/忌神（如"用神""忌神""喜""忌"）
   - 五行旺衰（如"火旺""土重""金水到位"）
3. 检查该句子是否包含命盘数据（大运干支、流年干支、十神、用神/忌神五行）
4. 若只有结论没有命盘数据，则违规

**正则模式**：
```python
# 流年判断模式
```
