# 积分明细页面字段清晰化

## 概述
将积分明细页面从卡片列表布局改为带表头的表格式布局，明确三列：操作时间、类型、积分变化；充值类型显示为"充值"，积分变化列充值显示 +XXX。

## 当前状态分析
- 文件：`mingli-agent/frontend/src/pages/PointsHistoryPage.tsx`
- 当前布局：无表头的垂直卡片列表（每行左侧显示类型文案+时间，右侧显示 ±积分）
- 类型映射 `bizTypeLabel`：`recharge` → "积分充值"（需改为"充值"）
- 积分变化已区分正负（充值 `+`、消耗 `-`），逻辑正确无需改

## 改动方案

### 文件：`mingli-agent/frontend/src/pages/PointsHistoryPage.tsx`

**1. 类型映射调整**
- `bizTypeLabel` 中 `recharge: '积分充值'` → `recharge: '充值'`

**2. 列表区改为表格式布局**
- 在明细列表容器顶部新增表头行，三列：`操作时间` | `类型` | `积分变化`（右对齐）
- 表头使用 `grid grid-cols-3` 三等分布局，小字号灰色样式
- 每条记录同样用 `grid grid-cols-3` 三等分，与表头对齐：
  - 第一列：操作时间（`formatTime` 结果，小字号灰色）
  - 第二列：类型（`itemLabel` 结果，正常字号深色）
  - 第三列：积分变化（右对齐，充值绿色 `+XXX`，消耗红色 `-XXX`）
- 移除原来的两行堆叠布局（时间在下、类型在上），改为单行三列

**3. 保留不变的部分**
- 顶部返回按钮 + 标题
- 当前积分卡片
- 加载中/错误/空状态展示
- `formatTime`、`itemLabel` 逻辑（仅改 bizTypeLabel 映射值）

## 验证
- `npm run build` 通过
- 页面展示三列表头，数据行与表头对齐
- 充值行类型显示"充值"、积分显示绿色 `+XXX`
- 首次报告/追问行类型显示对应文案、积分显示红色 `-XXX`
