# 评测中心结构优化

## 目标
将评测中心整合为统一页面，顶部 Tab 切换三个子页面，清晰区分数据来源（实验室评测 vs 生产监控）。

## 当前状态

### 路由结构（分散）
- `/admin/eval` → `EvalDashboard`（评测结果 + 评测集内容，2 个 Tab）
- `/admin/eval-overview` → `EvalOverview`（独立页面）
- `/admin/eval-detail/:id` → `EvalDetailPage`
- `/admin/eval-compare` → `EvalComparePage`

### 问题
1. 评测概览和评测结果是两个独立页面，用户需要在侧边栏切换
2. 数据来源不清晰：无法区分实验室评测（eval_dataset.json）和生产监控（用户实时报告）
3. 不同 eval_type 混在一起，没有按类型分组

### 数据来源
- **实验室评测**（`report_quality`、`chart_accuracy`、`badcase_eval`）：来自 `eval_dataset.json` 预定义用例，有预期结果
- **生产监控**（`production_monitor`）：来自用户实时生成的报告，智能采样后 LLM 评测，无预期结果

## 修改方案

### 1. 合并为统一页面 + 顶部 Tab

**文件**: `frontend/src/pages/EvalDashboard.tsx`

将 `EvalOverview` 的内容合并到 `EvalDashboard` 中，新增「评测概览」Tab：

```
评测中心
├── Tab 1: 评测概览（原 EvalOverview 内容）
│   ├── 核心指标卡片（5 个）
│   ├── 评测类型分布饼图
│   └── 最近评测列表
├── Tab 2: 评测结果（现有内容）
│   ├── 版本选择器 + 指标卡片
│   ├── 筛选区（评测类型 + 评测集ID）
│   └── 结果表格
└── Tab 3: 评测集内容（现有内容）
    ├── 最新评测结果摘要
    └── 用例列表
```

### 2. 数据来源标识

在「评测结果」Tab 的表格中，增加数据来源列：
- `report_quality` / `chart_accuracy` / `badcase_eval` → 标记为「实验室」
- `production_monitor` → 标记为「生产」

同时支持按数据来源筛选。

### 3. 路由调整

**文件**: `frontend/src/App.tsx`

- 保留 `/admin/eval` → 合并后的 `EvalDashboard`
- 删除 `/admin/eval-overview` 路由（功能已合并）
- 保留 `/admin/eval-detail/:id` 和 `/admin/eval-compare`

### 4. 删除独立页面

- 删除 `frontend/src/pages/EvalOverview.tsx`（内容已合并到 EvalDashboard）
