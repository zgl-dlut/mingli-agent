# 去除报告中的结构标签名称

## 任务概述

报告中出现了"开篇承接"、"全局核心总纲"、"分模块逐一解答客户问题"等 prompt 内部的结构标签名称，需要让模型直接输出内容，不显示这些元描述。

## 当前状态

`prompt_builder.py`（首次解读）和 `skill_prompts.py`（追问）中的 prompt 使用了明确的章节编号和标签：

**首次解读** (`prompt_builder.py` 第 159-210 行)：
```
## 开场白
## 一、八字基本盘与核心格局
## 二、性格特质与潜能画像
## 三、事业与财富发展核心策略
...
```

**追问** (`skill_prompts.py`)：
```
### 1. 开篇承接段
### 2. 全局核心总纲
### 3. 分模块逐一拆解用户所有问题
### 4. 文末综合最终决策建议
```

模型会忠实地把这些标签名称输出到报告中。

## 实施方案

### 修改1：`prompt_builder.py` — 首次解读 prompt

将结构标签改为**内容导向的标题**，让模型输出自然的章节标题而非元描述：

- `## 开场白` → 保留（这个是自然的）
- `## 一、八字基本盘与核心格局` → 保留（这个也是自然的）
- 其他类似 `## 二、` `## 三、` 的标题本身已经是内容导向的，无需改

首次解读的标题已经是内容导向的（"八字基本盘"、"性格特质"、"事业与财富"），问题主要在追问 prompt。

### 修改2：`skill_prompts.py` — 追问 prompt（4个专项 + 通用）

将所有 prompt 中的结构标签改为**内容导向的标题**：

- `### 1. 开篇承接段` → 去掉编号，改为 `### 命盘总览` 或直接让模型用自然开头
- `### 2. 全局核心总纲` → `### 年度运势总纲`
- `### 3. 分模块逐一拆解用户所有问题` → 去掉，让模型直接用问题相关的小节标题
- `### 4. 文末综合最终决策建议` → `### 综合行动建议`

**关键改动**：在 prompt 的输出结构说明中，明确告诉模型：
> "不要在正文中出现'开篇承接'、'全局核心总纲'、'分模块解答'等结构标签名称。直接用内容相关的标题，如'年度运势总纲'、'事业走势分析'等。"

## 涉及文件

| 文件 | 说明 |
|------|------|
| `backend/app/services/prompt_builder.py` | 首次解读 prompt（标题本身已OK，检查是否需要微调） |
| `backend/app/services/skill_prompts.py` | 追问 prompt（4个专项 + 1个通用，需要修改结构标签） |
