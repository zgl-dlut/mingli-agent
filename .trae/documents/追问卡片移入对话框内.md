# 追问卡片移入对话框内

## 目标
把"推荐追问 Chip 条"从底部输入栏上方，移到消息列表内，紧跟在最后一条 AI 回答气泡下方独立显示。触发时机不变：首次报告产出后、追问回复后直接给出 3 个追问问题。底部输入栏原位置完全移除，避免重复。

## 当前状态分析

### 关键文件
- [Chat.tsx](file:///Users/zhangguangling/Downloads/命理推算/mingli-agent/frontend/src/pages/Chat.tsx)

### 现有实现要点
1. **数据来源**：`extractSuggestedQuestions(content)`（L22-35）从最后一条 assistant 消息的 JSON content 解析 `suggested_questions`；`filterAsked`（L37-53）过滤已问过的问题。
2. **显示状态**：`showSuggested`（L170）控制显示。触发点：
   - 首次报告完成后 `setShowSuggested(true)`（L944-950 附近）
   - 追问回复完成后 `setShowSuggested(true)`（L1179-1187 附近）
   - 切换人物/重新进入时 `setShowSuggested(false)`（L642）
3. **当前渲染位置**：L1481-1520 的 IIFE 代码块，**嵌在底部输入栏内**（L1478 的 `<div className="bg-white/90 ...">` 容器里，输入行 L1522 之前）。渲染条件（L1484-1489）：
   - `showSuggested` 为 true
   - 存在最后一条 assistant 消息
   - 未在生成中（`!isPersonGenerating(person.id)`）
   - 输入框为空（`!inputValue`）
   - 提取到非空 `suggested_questions` 且过滤后仍非空
4. **消息列表结构**（L1376-1442）：`<div className="space-y-3">` 内依次是 `messages.map`（L1379-1405）、optimistic 用户消息（L1407-1416）、生成中提示（L1418-1441）、`messagesEndRef`（L1442）。AI 气泡为白色 `bg-white rounded-bl-sm`，用户气泡为棕色 `bg-[#8b6f5a] ml-9`（头像已移除，仅保留 `ml-9` 留白）。
5. **滚动定位 effect**（L587-634）：依赖 `suggestedVisible = showSuggested && !inputValue` 和 `lastMsgId` 触发，把本轮用户问题气泡贴顶。effect 不依赖卡片具体 DOM 位置，只看 `showSuggested` 状态，移动卡片不影响它。

### 为什么移动是安全的
- 卡片显示的判定条件 `showSuggested && !inputValue && !isPersonGenerating` 已经保证：卡片显示时，消息列表里 optimistic 用户消息和生成中提示都不存在，最后一条消息必定是 AI 回答。所以把卡片放在 `messages.map` 之后，视觉上一定紧跟最后一条 AI 回答气泡。
- 用户点击推荐问题（`handleSend(q)`）→ 发送后 `pendingUserMsg` 出现、`isPersonGenerating` 变 true → 卡片因 L1485 条件自动隐藏 → 回答完成后 `showSuggested` 重新置 true、新回答已落库 → 卡片重新显示紧跟新回答。链路自洽。
- 滚动 effect 用 `showSuggested` 状态而非 DOM 位置，移动卡片不影响滚动定位。

## 假设与决策
1. **卡片显示时一定紧跟最后一条 AI 回答**：由 `!inputValue && !isPersonGenerating` 条件保证，显示时 optimistic 用户消息和生成提示都不存在，messages 最后一条就是 AI 回答。
2. **卡片放在 messages.map 之后、optimistic 用户消息之前**：当卡片隐藏时（用户已发问题/生成中），optimistic 和生成提示正常显示不受影响；卡片显示时 optimistic 和生成提示都不存在，卡片自然紧贴 AI 回答。
3. **不修改后端**：`suggested_questions` 字段后端已正常返回（followup_structured.py + report_schema.py），本次纯前端 UI 位置调整。
4. **不修改头像相关**：用户已自行移除头像代码，本次不碰消息气泡渲染结构。
