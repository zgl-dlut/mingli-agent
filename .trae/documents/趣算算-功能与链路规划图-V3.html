02入口矩阵

每个入口必须回答四件事：用户此刻在想什么、带什么参数进来、落在对话哪一步、是否收费。
#入口触发时机带入参数落点计费
E1Tab 对话随时，默认打开上次会话当前档案（默认本人）对话首屏 / 历史会话按内容
E2今日页「问问 AI」新增看完日运，想追问今天怎么做流日干支 + 今日宜忌预填「今天适合推进什么事？」免费框架

03对话承载的能力

能力按“输入 → 免费部分 → 收费部分 → 输出去向”定义，避免同一能力在两个页面用不同规则收费。
能力输入免费部分收费部分输出去向复用页面
单盘问答命盘 + 问题 + 可选材料分析框架（4 维）、可改大纲60 分解锁正文；会员 10 次/月深度解读正文对话、半弹层、首读导流
关系解读2 人档案 + 关系类型 + 材料免费合盘摘要 + 4 维框架120 分解锁（会员 8 折 = 96）关系正文对话、星盘合盘页签

05冗余审计

判定标准：如果两处产出“同一份解释”或“同一套计费”，就合并；如果只是同一能力的两个壳，保留但统一状态。
#重叠对象问题判定处理
R1今日的月运 / 年报 vs 对话生成周期报告同一份周期报告两个生产地，价格与缓存容易不一致合并周期报告只在今日 / 报告中心生成；对话只做“引用报告追问”，不再生成同类报告
R2AI 半弹层 vs 对话页两个壳，若各存会话会出现“刚问过又得重问”保留统一半弹层 = 对话轻量壳，共享会话 / 额度 / 解锁；「⤢ 展开」升格不丢消息
R3首读 vs 更多解读 vs 深度解读都在解释命盘，用户分不清该买哪个分层保留首读 = 总览（建档交付）；更多解读 = 维度逐条（免费）；深度解读 = 单点深挖（60）
R4流盘 vs 年报都讲大运 / 流年，入口重复分工流盘 = 免费时间轴与段位；年报 = 年度叙事（160），入口从流盘当前段位进入
R5星盘「合盘」页签 vs 关系解读合盘完整长文与 120 报告重复合并合盘页签只放免费摘要（冲合 / 相处关键词），完整版统一走 120 关系解读
R6更多解读「同类交流地」产品暂无社区，点了是死链删除换成「大家常问」问题 chips，点击进 AI 半弹层
R7我的页报告入口 vs 报告中心两个列表，信息重复收敛我的页只显示最近 3 条 + 「查看全部」；完整列表只在报告中心
R8日运 vs 月运 vs 流盘流日颗粒度不同，但“今天”出现三次保留日运 = 行动建议；月运 = 月节奏；流盘流日 = 查具体日，仅做工具

06断链与补链

以下 6 处在当前 20 屏里“读到这里就结束”，用户没有下一步可点，或付费后没有反馈闭环。
#断点影响新增 / 修补落在哪屏
S1无档案新用户进对话没有盘可选，直接卡死空态首屏「先建档，1 分钟」内联建档，完成后回填对话05 对话首屏
S2今日页看完日运无去处免费流量不导流，D1 留存断日运卡底部「问问 AI 今天适合做什么」01 今日页
S3月运 / 年报读完即结束高价值读者无法转深读报告底部「带着这份报告问 AI」+ 引用卡03 / 04
S4深读生成 3 分钟，离开后不知道完成解锁了却看不到，退款与差评风险对话内进度卡 + 我的红点 + 报告中心「生成中」状态07 / 13 / 15
S5会员 10 次/月不可感知权益感知弱，续费动力低会员中心与解锁弹层显示「本月剩余 7/10」14 / 解锁弹层
S6关系 120 决策太重从 0 直接到 120，转化低先给免费合盘摘要（3 个冲合 + 2 条相处关键词）再解锁09 / 11
S7首读读完没有下一步首读是最大流量，未承接末尾「继续看：你的十神 / 大运」二选一16 星盘详情
S8报告中心只能看，不能问回看价值低每条报告右侧「继续问」13 报告中心
