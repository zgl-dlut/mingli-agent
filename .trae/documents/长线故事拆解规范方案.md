# 长线故事增强（补充拆解规范）

## 当前状态
L118 已加长线故事维度（延伸到 2028 长远剧情 + 严格依靠排盘不可胡编）。但只在 narrative 叙事规范里，子问题拆解规范没要求把长线剧情作为独立 subtopic。

## 改动

文件：`backend/app/services/followup_structured.py`

### 拆解规范（L98）补充长线维度
当前 L97-98：
```
   - 提取用户疑问里面所有关心点，每一个关注点对应一块分析
   - 额外补充风险提示、时间路线、实操对策
```
加一条：
```
   - 额外补充一个长线剧情subtopic：延伸到问题之后1-2年的职场成长剧本（如2028入职新公司后的平台跃迁、副业闭环、话语权变化），严格依靠排盘流年趋势推演，不可胡编乱造
```

这样 LLM 会把长线故事拆成独立 subtopic，而不只是 narrative 里提一句。
