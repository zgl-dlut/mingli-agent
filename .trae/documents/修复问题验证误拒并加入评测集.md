用户追问"2032年大额支出是不是就是因为我购房了"被 `validate_user_question` 误判为无效问题。需要修复疑问词和关键词匹配逻辑，并将该 case 及边界用例加入现有评测集。

## Current State Analysis

### Bug 根因
**文件**: `backend/app/services/skill_prompts.py` 第1203-1246行

用户问题: "2032年大额支出是不是就是因为我购房了"

被拒绝的完整链路：
1. `"是不是"` 不在 `question_words` 列表中（只有 `"是否"`，没有 `"是不是"`）
2. `"大额支出"`, `"购房"` 不在 `_CORE_RELEVANT_KEYWORDS` 中
3. `_match_skill_type()` 返回 `None`（SKILL_PROMPTS 中没有匹配关键词）
4. 走到第1230行：`not matched_skill and not has_question_word and not has_core_relevant` → 返回 False

`eval_dataset.json` 当前只包含报告质量评测（`report` + `chart_data` + `expected_pass`），没有问题验证类型。

### Step 4: 更新 run_eval.py 支持问题验证类型
**文件**: `backend/app/services/eval/run_eval.py`

在 `run_single_eval` 函数中添加问题验证分支：
```python
def run_single_eval(...):
    # 新增：问题验证类型
    if "user_question" in case and "report" not in case and "generated_chart" not in case:
        from app.services.skill_prompts import validate_user_question
        expected_pass = case.get("expected_pass", True)
        actual_pass, _ = validate_user_question(case["user_question"])
        return {
            "passed": actual_pass == expected_pass,
            "violations": [] if actual_pass == expected_pass else [{"type": "question_validation", "detail": f"预期{'通过' if expected_pass else '拒绝'}但实际{'通过' if actual_pass else '拒绝'}"}],
        }
```
